中长期股票操作提示词
更新日期：2026-05-31

定位：中长期股票负责 10 到 60 个交易日的趋势增强仓，目标是吃行业主线、趋势延续、估值修复或业绩/政策驱动的一段中期行情。它不使用短线 D2/D3 清仓，也不使用短线 +4% 必卖一半规则。

使用原则：
1）先读《工具脚本/70_长期持有股票/中长期选股策略.md》。
2）必须先判断市场模式、情绪周期、概念主线和行业强度。
3）只在趋势、板块、逻辑三者至少两者同向时考虑买入。
4）只接受三类买点：趋势回踩 MA20、平台突破、主线分歧低吸。
5）分批建仓，不一次打满；跌破 MA20 后不补仓摊平。
6）中长期不是扛亏理由。趋势、板块、逻辑坏掉就降仓或退出。

═══════════════════════════════════════════════════════════════
一、什么时候问中长期股票
═══════════════════════════════════════════════════════════════

适合问：
1）周末或收盘后：想布局 2 到 8 周的趋势股。
2）M3/M4、主线清晰时：想从强行业/强概念里找中期候选。
3）短线 S3/S4 票走强后：想判断能不能升级为中长期持仓。
4）每周复核：检查持仓趋势是否还在。
5）大涨后：想知道是否分批止盈。
6）大跌后：想知道是正常回踩、趋势破坏，还是必须清仓。
7）板块/概念变化后：判断原来的持有逻辑是否失效。

不适合问：
1）想今天尾盘买、明后天卖，用短线模板。
2）还没给出持仓成本和买入逻辑，却要求判断能不能长期拿。

我的当前情况：
1）中长期股票可用资金：____
2）当前中长期持仓：
- 股票/代码，成本 ____，仓位 ____，持有天数 ____，买入逻辑 ____
3）总账户里中长期股票 / 短线股票当前比例：____ / ____
4）我这次想解决的问题：新建仓 / 找观察池 / 检查持仓 / 是否从短线升级中长期

请你执行：
1）跑 market_mode.py 判断 M1-M5 和情绪周期。

【持有逻辑】趋势证据 / 板块证据 / 量价证据 / 筹码证据 / 基本面或事件持续性
【风控】MA20处理 / MA60处理 / 板块退潮处理 / 止盈计划 / 反证条件
【事实/推断/不确定】分开列明
【胜率-赔率-确定性】胜率感 / 赔率 / 确定性 / 置信度

六、短线升级中长期模板
═══════════════════════════════════════════════════════════════

短线票是否升级中长期：
股票/代码：____
短线买入策略：S1 / S2 / S3 / S4
买入价：____
当前价：____
当前浮盈亏：____
持有 D几：____
原短线逻辑：____
我想升级的原因：____

请判断是否允许从短线升级为中长期：
1）短线逻辑是否仍有效，有没有触发短线逻辑失效。
2）所属概念/板块是否从短线情绪扩散为中期主线。
3）股价是否站稳 MA20，回踩是否不破。
4）中长期评分是否达到 A 或高 B。
5）如果升级，重新写中长期仓位、止损、止盈和复核节奏。
6）如果不升级，仍按短线 D2/D3 默认退出与R1授权纪律处理；不得把R1等同于升级中长期。

请输出：
【能否升级】可以 / 暂不可以 / 不能
【原因】事实 / 推断 / 不确定
【升级后计划】仓位 / MA20失效 / MA60失效 / 止盈 / 下次复核
【不升级处理】按短线规则何时卖、怎么卖
