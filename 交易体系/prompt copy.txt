请使用最新、可验证的数据，对以下三类固定对象进行深度分析：

1. 上证指数；
2. 我指定的主攻板块；
3. 我指定的持仓股票。

你的任务不是简单预测涨跌，而是帮助我提前建立“关键位置—确认信号—后续路径—操作条件”的完整地图，让我可以先自行画出压力、支撑，再与你的答案进行对照学习。

====================
二、数据要求
====================

1. 必须先获取并核验最新数据，再开始分析。

2. 盘中分析使用实时行情；收盘后使用当天最终收盘数据。禁止把盘中快照当成最终收盘价。

3. 明确写出：
   - 数据日期和截止时间；
   - 使用的是实时数据还是收盘数据；
   - 个股、指数和板块数据是否为同一交易日；
   - 存在哪些缺失数据或异常数据。

4. 至少获取和检查：
   - 最近60个交易日的日K；
   - 最近20日和60日高低点；
   - MA5、MA10、MA20、MA60；
   - ATR14或近期平均振幅；
   - 当日开盘、最高、最低、收盘；
   - 成交额、成交量及20日均量；
   - 最近显著放量K线；
   - 跳空缺口、横盘平台和整数关口。

5. 分析上证指数时，还必须检查：
   - 上证50；
   - 沪深300；
   - 深证成指；
   - 创业板指；
   - 全市场上涨/下跌家数；
   - 全市场成交额；
   - 主要权重方向是否同步。

6. 分析板块时，还必须检查：
   - 板块今日涨跌幅；
   - 最近3日、5日、10日强度；
   - 相对上证及三大指数的超额收益；
   - 板块上涨家数、下跌家数和上涨宽度；
   - 板块中位涨幅；
   - 龙头、核心权重及高弹性股票的同步程度；
   - 是核心驱动、全面扩散，还是少数股票单点拉升；
   - 板块成交额、量能变化和尾盘收位。

7. 分析持仓股票时，还必须检查：
   - 当前价与持仓成本的距离；
   - 股票所属三级行业；
   - 股票相对板块、相对上证的强弱；
   - 当日收盘位置；
   - 最近的放量上涨或放量下跌K线；
   - 持仓成本、平台、均线和前高前低是否形成共振；
   - 如果数据库已有止损、目标或持仓期限，必须同时读取。

====================
三、关键点位定义
====================

必须按以下规则确定关键位置：

1. 压力1：
   当前价格上方最近、最可能影响短线走势的有效压力区。

2. 压力2：
   有效突破压力1后，下一个相对独立的重要压力区。

3. 支撑1：
   当前价格下方最近、最可能产生承接的有效支撑区。

4. 支撑2：
   有效跌破支撑1后，下一个相对独立的重要支撑区。

5. 如果两个位置距离过近，应合并为一个区域，然后寻找下一个真正独立的压力或支撑。

6. 不允许仅凭单一均线、单一整数位、单一趋势线或黄金分割确定关键位置。

7. 每个位置至少需要两项客观证据。优先级如下：
   - 周线、日线显著前高前低；
   - 最近20日、60日高低点；
   - 放量突破平台；
   - 大成交量K线开盘价、收盘价或实体区间；
   - 跳空缺口；
   - 横盘成交密集区；
   - MA20、MA60等重要均线；
   - 整数心理关口；
   - 板块核心股同步位置。

8. 压力和支撑必须使用“小而诚实”的区间，不能只给一个精确点，也不能故意给很宽的模糊范围。

区间总宽度原则上控制在：
   - 约0.10—0.15倍ATR14；
   - 或正常最小价格波动的3—5倍；
   - 两者取较合理者。

如果因为高波动必须扩大区间，需要明确说明原因。

9. 每个位置都要给出“强度评分”：
   - 5分：多周期、多证据强共振；
   - 4分：较强关键位置；
   - 3分：普通观察位置；
   - 2分以下：弱位置，不应作为主要交易依据。

====================
四、突破和跌破标准
====================

禁止把盘中瞬间刺穿直接定义为有效突破或有效跌破。

针对不同对象分别制定确认条件，不能复制同一套话。

【上证指数有效突破条件】

至少结合：
1. 收盘是否站上压力区上沿；
2. 是否放量；
3. 上涨家数是否扩张；
4. 上证50、沪深300是否同步；
5. 深证成指、创业板是否明显拖后腿；
6. 次日是否能够守住或完成回踩确认。

【板块有效突破条件】

至少结合：
1. 板块收盘站上压力区；
2. 板块量能是否增加；
3. 上涨宽度是否达到合理水平；
4. 龙头、核心权重、高弹性股票是否同步；
5. 是否具有相对大盘的超额收益；
6. 是否属于全面扩散，而非单点拉升。

【持仓股票有效突破条件】

至少结合：
1. 收盘站上压力区上沿；
2. 成交量相对20日均量的比例；
3. 收盘位置；
4. 是否留下明显长上影；
5. 所属板块是否同步；
6. 次日是否回踩不破；
7. 是否存在高开过度、盈亏比下降的问题。

【有效跌破条件】

必须分别说明：
1. 是盘中跌破还是收盘跌破；
2. 是否放量；
3. 是否快速收回；
4. 板块和核心股是否同步转弱；
5. 跌破后是否反抽原支撑失败；
6. 跌破支撑1后，向支撑2运行的概率是否明显上升。

首先输出总表：

|---|---:|---:|---:|---:|---|---:|---:|---:|---:|---|---|

表格之后，按以下顺序逐一展开：

====================
A. 上证指数
====================

1. 当前趋势状态：
   上升、震荡、调整、退潮中的哪一种。

2. 压力1：
   - 具体小区间；
   - 形成依据；
   - 共振因素；
   - 强度评分；
   - 为什么选择这里，而不是附近其他位置；
   - 突破后预计先向哪里运行。

3. 压力2：
   同样详细说明。

4. 有效突破条件：
   给出明确可检查的收盘、量能、市场广度和权重确认标准。

5. 支撑1：
   - 具体小区间；
   - 形成依据；
   - 共振因素；

   - 第一次回踩还是多次测试；

6. 支撑2：
   同样详细说明。

7. 有效跌破条件：
   给出明确的收盘、量能、广度和反抽失败标准。

8. 三种情景：
   - 强势突破；
   - 区间震荡；
   - 有效跌破。

每种情景都说明：
   - 触发条件；
   - 下一目标区域；
   - 什么现象证明判断错误；
   - 当前不应做什么。

====================
六、逻辑和教学要求
====================

1. 所有事实、推断和不确定性必须分开表达。

2. 每一个关键位置都要解释：
   - 它是怎么找到的；
   - 为什么市场参与者可能关注它；
   - 它附近可能聚集哪些买盘、卖盘、止损盘或解套盘；
   - 为什么突破或跌破后可能加速。

3. 必须说明：
   - 支撑不是必然止跌；
   - 压力不是必然回落；
   - 关键位置只是市场更可能作出方向选择的区域。

4. 不要使用“肯定上涨”“一定跌到”等绝对表达。

5. 如果证据不足，应写“位置可信度低”，不能为了完整而编造点位。

6. 如果压力或支撑来自单一技术指标，必须降级处理。

7. 对于每一个结论都写出反证条件。

8. 突破后原压力转为支撑、跌破后原支撑转为压力，都必须等待回踩或反抽确认，不能自动认定角色转换成功。

9. 最后输出一份“我自己画点位时的检查答案”：

   - 我最容易遗漏的证据；
   - 我最容易把什么误判成突破；
   - 今天哪个位置最值得重点学习；
   - 哪个位置虽然明显，但实际交易价值不高；
   - 明天盘中应该先观察什么，再观察什么。

====================
七、最终结论
====================

最后必须给出：

1. 上证指数最重要的一组压力和支撑；
2. 主攻板块强弱排序；
3. 每个板块最关键的突破/跌破触发器；
4. 持仓股票风险排序；
5. 明日观察顺序：
   大盘 → 板块 → 个股；
6. 哪些位置适合观察，哪些位置具备操作价值，哪些属于区间中部禁止操作；
7. 结论置信度及其主要限制。

请以详细教学为主，不要只给表格和结论。
