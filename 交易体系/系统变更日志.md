# 系统变更日志

> 目的：让"边走边优化"可复盘。每改一处就记一条，月末按版本分段看胜率，而不是一锅烩。
> 配套：`trade_log.py buy` 会自动给每笔交易打 `CURRENT_SYSVER`（脚本顶部常量）。**改了逻辑就 bump 这个常量，并在这里记一条。**

---

## 记录格式（每条4要素）

```
### vN  YYYY-MM-DD  一句话标题
- 改了什么：具体到文件/函数/阈值（旧值 → 新值）
- 为什么改：触发它的那个观察（哪笔交易/哪天盘面/复现结果）
- 期望：这条改动应该带来什么（更多/更少候选、少踩哪种坑、盈亏比变化）
- 类型：[Bug修复] 立即上 ／ [放松风控] 慎重·最好影子先跑几天
```

## 两档速度（决定该不该立即上）

- **[Bug修复]**：本来就没按设计工作（如 S4 死代码、NaN 换手绕过市值过滤、止损倒挂）。**立即改**，不叫"改策略"。
- **[放松风控]**：松高潮×0.5、松追高门槛、放宽止损、放宽评分门槛等**降低下行保护**的调参。**最容易被最近几天行情骗、在顶部爆掉**。要求：先历史复现证明是真问题 → 最好影子跑几天 → 再正式上。
- **[加严/中性]**：收紧门槛、加排除项、纯展示/记录类。风险低，可较快上。

## 月末怎么用

```
python 工具脚本/50_交易记录/trade_log.py calibration --by version    # 分版本看胜率/盈亏/破纪律
python 工具脚本/50_交易记录/trade_log.py calibration --by strategy
python 工具脚本/50_交易记录/trade_log.py calibration --by mode
```
对比"改动前版本"和"改动后版本"的表现，用你自己的实盘数据决定：这条优化该保留、回滚、还是继续调。

### v8  2026-08-07  R1滚动持有授权：时间规则软化，利润保护硬化
- 触发：实盘讨论发现“D2/D3到期一律只卖不买”会把持有期限误当成行情预测，尤其无法表达PCB强趋势股在已经兑现部分利润后仍有正向预期的情形；但2026-07-02的S4研究也已证明，宽泛的“持到破MA5”或“盈利就延长”在winsorize去极值后全面弱于D2，优势主要由极少数+50%~97%怪兽单贡献，不能直接全面放开。
- 改了什么：
  ① D2/D3从“无条件清仓日”改为“默认退出/重新证明日”；没有显式有效授权仍按原时间退出，亏损单和未首次兑现的持仓不得延期。
  ② 新增R1授权门槛：先完成D1首次兑现、授权时相对原买入价仍盈利≥2%；市场、板块、相对强度、价格/量能、剩余赔率五项至少4/5，且市场/板块/价格量能/剩余赔率四项必过；下一目标空间÷到保护线风险必须≥1.5。
  ③ 利润保护线必须≥成本+1%、低于授权时现价并且只许上移；单次原则上只覆盖下一交易日，到期可凭新证据续签，未续签自动恢复D2/D3默认退出。
  ④ `trade_log.py` 新增 `cashout` 记录首次部分兑现（交易保持open、跟踪剩余股数和已实现利润）与 `authorize-hold`；R1不再接受口头“已兑现”开关，必须查到cashout记录。最终全平时合并部分兑现和剩余仓盈亏；`audit-open`识别授权有效与过期，`calibration --by hold`支持以后用实盘数据单独校准R1。
  ⑤ `realtime_guard.py sell`识别R1：有效期内不因D2/D3机械清仓，不重复触发首次卖50%；保护线失守、移动止盈、强势目标、熔断和原逻辑失效仍优先。
  ⑥ R1只管理首次兑现后的剩余仓，不授权净加仓；做T只允许先卖后买，回补≤当日已卖数量，收盘仓位不高于授权前剩余仓。同步更新短线主提示词、操作手册、防臆想规则、参数手册和思维导图。`CURRENT_SYSVER` v7→v8。
- 验证：交易记录/实时守卫21项测试通过，覆盖部分兑现保持open、剩余股数、整笔盈亏合并、首次兑现/盈利线、四个核心证据、剩余赔率、保护线只上移、短授权、有效授权覆盖到期、过期恢复退出、保护线失守与授权目标止盈；相邻市场/狙击执行15项回归测试也通过。R1表现需用 `calibration --by hold` 与非R1剩余仓分组跟踪，不能用单只强票证明规则有效。
- 期望：保留短线期限闸门对普通交易的止损作用，同时让真正已经赚钱、主线与量价仍健康、剩余赔率仍合算的仓位继续创造利润；把“灵活”变成可验证、可撤销、可复盘的权限。
- 类型：[受控放松风控] 正式小样本试运行。不是推翻2026-07-02研究：仍拒绝无条件持到MA5，只给锁定利润后的剩余仓逐日授权；累计至少20次授权后复核门槛与期望。
