# 盘前反弹雷达

用途：识别“高景气科技深度回撤后，隔夜风险逆转点火，竞价核心股联动，开盘后板块扩散”的第一根修复阳线。

该雷达与原有市场模式并行：原有 M5、MA10、MA20 和情绪周期继续负责趋势与仓位；雷达只负责早预警，不修改市场模式、不自动下单。

## 四级信号

| 级别 | 含义 | 核心证据 | 动作 |
|---|---|---|---|
| R0 弹簧 | 高景气科技已充分去杠杆 | 10/20日跌幅、MA20下方宽度、距MA20 | 进入次日观察池 |
| R1 点火 | 隔夜风险逆转 | 纳指/费半必须至少一项转强；美债、VIX、油价辅助 | 黄色预警，不买 |
| R2 竞价 | 国内核心确认 | 中际旭创、新易盛、天孚通信至少2只同步高开 | 准备实时计划 |
| R3 扩散 | 不是单票诱多 | 高质量科技篮子上涨宽度、涨幅中位数、核心承接、成长风格差 | 仅进入小仓交易评估 |

油价下跌只有在此前五日已经上涨时才加分，防止把需求衰退型油价下跌误判成科技利好。美债、油价、VIX不能脱离纳指/费半单独触发R1。

## 默认参数

- R0：20日收益中位数≤-15%或10日≤-10%，MA20下方占比≥65%，综合至少5分。
- R1：纳指≥+1.0%或费半≥+1.5%是硬前提；综合分≥2.5。
- R2：核心三股至少2只高开≥1.5%；高开中位数≥6%仍记录反弹事件，但硬性标记“禁止追高”。
- R3：09:40确认；上涨宽度目标≥70%、硬底线60%；篮子中位涨幅≥1.0%；至少2只核心不低于开盘价；四类证据至少满足3类。
- 数据覆盖率不足70%时不触发。

“识别信号”和“可执行评估”是两个字段：例如核心竞价中位高开超过6%，板块随后继续上涨，雷达可以正确识别反弹，但不会允许在09:40追入。

这些参数优先保证因果完整和邻近阈值稳定，不以单次最高收益为目标。两周样本只能用于排除明显不合理参数，不能证明长期胜率。

## 参数影响与选值逻辑

### R0：弹簧状态，不拿它做精确择时

| 参数 | 放宽会怎样 | 收紧会怎样 | 采用值与理由 |
|---|---|---|---|
| 20日收益中位数 | 更早进入观察，但普通调整也会混入 | 只剩极端超跌，容易等到反弹已发生 | -15%；覆盖一轮明显估值压缩，又不要求崩盘 |
| 10日收益中位数 | 对短期急跌更敏感，也更容易受事件冲击干扰 | 漏掉“急跌后立刻修复” | -10%；与20日条件取“或”，专门抓加速下跌 |
| MA20下方宽度 | 少数龙头回撤也可触发，容易把个股利空当板块机会 | 必须全板块超跌，预警太迟 | 65%；要求多数成分同步去杠杆 |
| 距MA20中位数 | 会接纳贴着均线的普通震荡 | 只抓远离均线的极端乖离 | -7%；作为评分项，不单独形成硬门槛 |
| R0最低分 | 频率上升但“跌幅、宽度、乖离”可能只满足一类 | 状态确认更纯，但错过快速杀跌 | 5分；同时保留跌幅与宽度两个硬条件 |

R0连续多日通过是正常现象。它表达的是“有弹性”，不是“明天必反弹”；真正的日期选择由R1—R3完成。

### R1：隔夜点火，必须有科技资产自身确认

| 参数 | 放宽会怎样 | 收紧会怎样 | 采用值与理由 |
|---|---|---|---|
| 纳指涨幅 | +0.5%左右的普通波动也会加分 | 只有大阳线才预警，次数很少 | +1.0%；今天+2.1%，有清晰风险偏好切换 |
| 费半涨幅 | 更敏感但噪声高 | 会漏掉纳指强、费半温和跟涨的组合 | +1.5%；比纳指要求更高，体现行业弹性 |
| 美债10Y变化 | 小幅利率波动也算贴现率改善 | 只认剧烈利率下行 | -4bp；今天-5.9bp，刚好提供第二条独立因果证据 |
| VIX变化 | 普通波动率回落也加分 | 只认可恐慌显著解除 | -5%；仅0.5分，避免VIX主导方向判断 |
| Brent变化/前5日 | 任意油跌都被误当利好 | 很少识别通胀冲击逆转 | 当日≤-2.5%且此前5日≥+3%；需求衰退型油跌不加分 |
| R1最低分 | 单一科技上涨就可触发，误报增多 | 需要多资产同时大幅变化，容易错过 | 2.5分；强科技（含幅度加分）+一项宏观配合 |

今天费半约+1.1%，没有越过1.5%线；真正让R1从1.5分升到2.5分的是10年美债下行5.9bp。这也是必须统一`^TNX`口径为“收益率百分点×100=bp”的原因。

### R2：竞价确认国内资金是否接力

| 参数 | 放宽会怎样 | 收紧会怎样 | 采用值与理由 |
|---|---|---|---|
| 核心高开阈值 | 小幅红开也算联动 | 容易只剩高潮日 | +1.5%；过滤随机平开，同时给正常高开留空间 |
| 核心数量 | 单只龙头异动就通过 | 三只必须全过线，受个股消息拖累 | 2/3；降低单票诱多，也不要求完美一致 |
| 创业板高开 | 对指数确认要求更低 | 板块强但指数被其他权重拖累时会漏 | +0.2%；只是加分项 |
| 成长/上证竞价差 | 风格不突出也加分 | 只抓极端成长占优 | +0.5pct；确保不是全市场无差别高开 |
| R2最低分 | 仅核心2/3即可过关 | 必须指数和风格也全面配合 | 3分；核心联动是硬条件，再要一项广义确认 |
| 竞价过热线 | 太低会把今天这类正常强开也禁掉 | 太高会允许高潮追入 | 6%；今天核心中位+4.2%可评估，7月31日+12.4%硬禁追 |

### R3：09:40验证扩散与承接

| 参数 | 放宽会怎样 | 收紧会怎样 | 采用值与理由 |
|---|---|---|---|
| 确认时点 | 越早越有价格优势，但首根5分钟噪声大 | 越晚越可靠，也越容易追在脉冲高点 | 09:40；看完两根完整5分钟K，是速度与稳定性的折中 |
| 上涨宽度目标/硬底 | 容许少数龙头拉升 | 需要近乎普涨，信号很稀少 | 70%目标、60%硬底；硬底防止评分补偿掉板块不扩散 |
| 篮子涨幅中位数 | 微弱红盘也算强 | 只认已经大涨的板块 | +1.0%；要求有实质强度但不追求高潮 |
| 核心站开盘价数量 | 一只承接即可 | 三只都不能回落，过于苛刻 | 2/3；同时是硬门槛，防高开低走 |
| 成长/上证强弱差 | 市场普涨也算科技独立强 | 只认明显风格极化 | +0.8pct；证明收益来自成长风格而非Beta |
| 同时段量速 | 缩量反弹也能加分 | 要求显著放量，可能受数据口径影响 | 1.10x；只作可选组件，缺失时不判失败 |
| 确认组件数 | 两类证据即可，误报提高 | 四类证据齐备，信号明显滞后 | 3类；但宽度硬底与核心承接无论如何必须满足 |
| 数据覆盖率 | 少量成分也可代表板块 | 数据偶发缺失就停机 | 70%；低于此值直接不触发，不用缺失值猜方向 |

回放标签“板块收盘中位≥2%、上涨宽度≥70%、创业板≥1.5%”只定义事后是否发生了目标反弹，不参与任何盘前或盘中打分。

## 2026-07-21至2026-08-03两周回放

- 10个交易日中，目标反弹共有3次：7月21日、7月27日、7月31日。
- 默认全链路只识别7月31日：事件识别1次、命中1次、误报0次，样本内精确率100%、召回率33%。样本极小，百分比不能外推成长期胜率。
- 7月31日核心三股竞价高开中位达到+12.4%，09:40板块中位已+10.0%；雷达识别反弹，但6%过热线禁止执行。若把过热线放宽到13%，09:40追入至收盘的篮子中位收益为-4.0%。
- 7月21日是开盘后才形成的V形修复：隔夜没有R1，09:40宽度只有61%、中位涨幅+0.5%，因此没有提前触发；其后反弹不属于本雷达针对的“隔夜点火+竞价同步”类型。
- 7月27日主要是国内盘中后发修复：R1、R2、R3在09:40均未通过，同样不是本雷达的目标形态。
- R3时点从09:35、09:40、09:45到09:50，全链路识别结果均只有7月31日；推迟到10:00/10:30虽然让R3单级多覆盖1个目标日，但全链路没有新增信号。因此选择09:40，少付出20—50分钟价格成本。

这段回放的作用是验证“今天这一类外部点火型反弹”能否被前置识别，并检查门槛有没有明显失真；它没有证明雷达能够抓住所有反弹。要估计长期胜率，至少还需要跨越不同市场状态的60—120个交易日样本。

## 使用

```powershell
python 工具脚本\20_市场环境\premarket_reversal_radar.py
python 工具脚本\20_市场环境\premarket_reversal_radar.py --backtest-days 10 --as-of 2026-08-03 --sensitivity
python 工具脚本\20_市场环境\test_premarket_reversal_radar.py
```

实时模式读取本地只读K线、Yahoo隔夜行情和腾讯实时行情。回放模式使用当时可见的前一日K线、当日开盘价和Yahoo 5分钟K；09:40确认不使用收盘数据。回放的“目标反弹”标签只用于事后评价，不参与信号生成。

## 失效条件

- 盘中科技篮子上涨宽度跌破60%。
- 核心三股中不足2只守住开盘价。
- 隔夜只有油价或美债变化，纳指与费半没有转强。
- 数据覆盖率不足70%。
- 原有市场硬否决触发。雷达不能绕过M5仓位和个股止损纪律。
