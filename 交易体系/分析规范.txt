一、数据拉取规则（最高优先级）
═══════════════════════════════════════════════════════════════

    ❗ 每次我问任何股票相关问题时，无论开盘还是收盘，必须先拉取最新数据再分析。
    ❗ 绝对不允许只根据之前的笔记、上下文、历史对话来判断，必须拿到当下最新数据。
    ❗ "最新数据"包括三类：
        ① 实时行情（通过 tmp_rt.py 拉取当前价/盘口/量能）
        ② 历史K线（通过 batch_fetch.py / cn_stock_analysis.py 拉取120天数据）
        ③ 概念主线数据（通过 _fetch_concept_data.py / concept_rotation.py 获取概念历史、主线阶段、分歧/退潮）

    何时拉实时行情：
        · 开盘时间（9:30-15:00）→ 必拉实时行情，这是决策的基础
        · 收盘后 → 拉实时行情获取今日收盘数据（腾讯接口会保留收盘快照）
        · 隔夜/周末 → 拉实时获取最后一个交易日的收盘数据

    何时拉120天历史：
        · 首次分析一只新股票时 → 必拉120天
        · 已分析过但超过3个交易日 → 重新拉120天
        · 当天出现重大变化（暴涨/暴跌/突破/破位）→ 重新拉120天
        · 我明确要求"深度分析"时 → 重新拉120天


二、分析维度（深度研判模式，默认使用）
═══════════════════════════════════════════════════════════════

    每次分析一只股票时，除了K线和量价数据，还需要尽可能关注以下维度：

    【必查维度】
    ① 大盘环境
        · 上证指数、深证成指、创业板指当日表现
        · 大盘处于什么状态？（上升/震荡/下跌/恐慌）
        · 大盘环境是否适合操作？

    ①-b 涨停板生态 ★V6.1新增★
        · 涨停家数(3日均值)、跌停家数
        · 涨跌比（>1多头主导，<1空头主导）
        · 昨日涨停→今日表现（资金接力意愿）
        · 连板高度（市场投机热度）
        · 情绪周期阶段（冰点/修复/发酵/高潮/分歧/退潮）

    ② 板块/行业动态
        · 该股所属板块今天涨跌情况
        · 板块是领涨/跟涨/领跌？
        · 是否有板块轮动到该行业的迹象？
        · 板块轮动预判：🔺新晋强势 vs 🔻退潮 ★V6.1新增★

    ②-a 概念主线动态 ★V9新增★
        · 今天市场主线概念有哪些？是否有连续性，而不是一日游？
        · 概念处于启动/发酵/主线/分歧/高潮/退潮哪个阶段？
        · 主线概念今日预计是延续、分歧、修复，还是退潮？
        · 若是主线分歧，是否满足低吸条件：龙头不破位、概念仍在MA20上、内部前排承接强？
        · 若是高潮/退潮，是否应只止盈不新开仓？

    ②-b 梯队定位 ★V6.1新增★
        · 该股在板块内5日涨幅排名是前15%(龙头)、前50%(跟风)、还是后50%(补涨)?
        · 优先买龙头，回避补涨

    ③ 北向资金/主力资金流向
        · 北向资金当日净流入还是净流出？
        · 该股主力资金净流入情况（如果能获取）
        · 外/内盘比作为替代指标判断资金方向

    ④ 相关新闻/公告
        · 近期是否有重大公告（财报、分红、增减持、定增等）
        · 行业政策变化
        · 突发事件（如美伊冲突、关税政策等宏观因素）

    【尽量查的维度】
    ⑤ 同行业个股对比
        · 同板块其他龙头今日表现如何？
        · 该股在板块中是领先还是滞后？
        · 板块内是否有联动效应？

    ⑥ 融资融券数据
        · 融资余额增减趋势（判断杠杆资金方向）
        · 融券卖出量（判断做空力量）

    ⑦ 关键价位时间窗口预判
        · 基于历史走势、均线收敛速度、量能趋势，
          预判下一个关键变盘节点大约在什么时间
        · 例如："按当前缩量速度，量比降到0.5以下预计还需2-3个交易日，
          最快4/7可能出现变盘信号"
        · 关键均线交叉的预估时间
        · 横盘整理的预估结束时间窗口

    【数据获取方式】
    · 个股K线/量价 → baostock（batch_fetch.py / cn_stock_analysis.py）
    · 实时盘口 → 腾讯财经接口（tmp_rt.py）
    · 大盘指数历史 → baostock（market_top_down.py）
    · 大盘实时 → 可用腾讯接口拉取 sh000001/sz399001/sz399006
    · 涨停板生态/情绪周期 → market_sentiment.py（涨停统计、接力分析、周期判定） ← V6.1新增！
    · 市场模式判定 → market_mode.py（自动集成情绪周期数据） ← V6.1升级！
    · 板块行业数据 → _fetch_market_data.py 刷新数据 → sector_daily表(81个行业每日统计) ← V3+新增！
    · 板块过滤规则 → 按市场模式动态调整淘汰线（详见选股参数手册V6.1·板块过滤阈值表） ← V6.1更新！
    · 板块轮动预判 → market_sentiment.py 的 sector_rotation 输出 ← V6.1新增！
    · 概念数据更新 → _fetch_concept_data.py（concept_info/concept_member/concept_daily） ← V9新增！
    · 概念主线分析 → concept_rotation.py（主线/发酵/分歧低吸/高潮/退潮） ← V9新增！
    · 梯队定位 → offline_screener.py 自动计算个股板块内排名 ← V6.1新增！
    · 板块对比分析 → gold_compare.py 等板块分析脚本
    · 新闻/公告/板块/资金 → 结合已知信息 + 如有网页工具可抓取
    · 无法获取的数据 → 明确告知我"此项无法获取"，不要跳过或忽略


二(补)、自上而下分析流程（2026-04-15更新·V6.1情绪周期版）
═══════════════════════════════════════════════════════════════

    ❗ 每次选股/分析前，必须先走完"大盘→模式判定→情绪周期→概念主线→行业板块→个股"六步流程。
    ❗ 大盘环境不好时（情绪≤2分），直接告诉我"今天不宜操作"，不要硬分析个股。

    第1步：运行 market_top_down.py 获取大盘120天历史分析
        → 输出三大指数趋势、量能、情绪评分

    第1.5步：运行 market_mode.py 判定市场模式+情绪周期 ★V6.1升级★
        → 输出当前模式(M1磨底~M5极端)
        → 输出允许的策略列表和对应参数
        → 输出板块淘汰线(sector_cutoff)
        → 输出S3 X2放宽阈值
        → 情绪≤1或≥10 → M5极端 → 不开新仓
        → 情绪≤3 → M1磨底 → 只用S1
        → 情绪4-5 → M2震荡 → S1+S2
        → 情绪6-7 → M3反弹 → S2+S3为主，S1仓位×0.3试探
        → 情绪≥8 → M4强趋势 → S3+S2为主，S1仓位×0.3试探
        ★V6.1新增输出：
        → 情绪周期阶段(冰点/修复/发酵/高潮/分歧/退潮)
        → 仓位修正器(position_modifier)：1.0正常/0.5减半/0禁止
        → 板块轮动预判(🔺新晋强势/🔻退潮板块)

    第1.6步：情绪周期二次校验 ★V6.1新增★
        → 若情绪周期=高潮日 → 仓位减半，提前止盈
        → 若情绪周期=分歧日 → 仓位减半，只做龙头
        → 若情绪周期=退潮/过热 → 强制M5空仓，不开新仓
        → 若position_modifier<1.0 → 明确告知风险

    第1.7步：运行 concept_rotation.py 判断概念主线 ★V9新增★
        → 输出主线概念TOP、分歧低吸观察池、新晋发酵、高潮谨慎、退潮回避
        → 主线概念：可顺势寻找S2/S3或主线内S1蓄力前排
        → 主线分歧：只等前排/龙头低吸，必须确认龙头不破位、概念未退潮
        → 新晋发酵：允许小仓试错，但必须看到概念内多股同步
        → 高潮谨慎：不追后排，只做持仓止盈或等待下一次分歧
        → 退潮回避：即使个股形态达标，也降级观察或回避

    第2步：确定强势板块（V8·只看强板块准入线）
        → 运行 python _fetch_market_data.py 刷新板块数据
        → sector_daily表自动计算81个行业每日涨跌、量能、动量
        → 按模式调整板块准入线：
            M1 → S1前50%
            M2 → S1前50%，S2前40%
            M3反弹 → S1前40%，S2前30%，S3前30% ★只做最强板块★
            M4强趋势 → S2前30%，S3前25% ★只看龙头板块★
        → 板块内≥3只同步走强才算板块效应
        → 同板块只取5日涨幅TOP3个股（板块龙头优先）★V6新增★
        → 优先选🔺新晋强势板块，回避🔻退潮板块 ★V6.1新增★

    第3步：板块内个股筛选（按模式选择策略+梯队定位）
        → 根据第1.5步判定的模式，运行对应策略
        → 非主力策略仓位×0.3试探，不完全禁用（M5除外）
        → 同行业硬性只推1只（最高分）
        → 标注个股梯队(龙头/跟风/补涨)，优先选龙头 ★V6.1新增★
        → 给出明确的买入区间、止损位、止盈位、仓位
        → 仓位按position_modifier修正 ★V6.1新增★


二(补2)、强制评分门槛（V5多策略版，防止"看着不错就推"）
═══════════════════════════════════════════════════════════════

    ❗ 不管股票来源是什么（系统扫描、用户点名、尾盘实时筛选），
       推荐买入之前必须完成以下全部步骤，缺一不可：

    ══ 策略选择（V6市场模式版） ══
    ❗ 先运行 market_mode.py 获取当前模式(M1-M5)
    ❗ 按模式决定策略仓位，非主力策略仓位×0.3试探

    模式→策略映射（V8·仓位缩放版）：
    · M1磨底(情绪1-3)    → S1(主力)，S2/S3仓位×0.3试探
    · M2震荡(情绪4-5)    → S1 + S2，S3仓位×0.3试探
    · M3反弹(情绪6-7)    → S2(主力) + S3，S1仓位×0.3试探
    · M4强趋势(情绪8-9)  → S3(主力) + S2，S1仓位×0.3试探
    · M5极端(≤1或≥10)    → 空仓，全禁用

    模式→板块准入线（V8·只看强板块）：
    · M1    → S1前50%
    · M2    → S1前50%，S2前40%
    · M3    → S1前40%，S2前30%，S3前30%
    · M4    → S2前30%，S3前25%

    模式→S3 X2(5日涨幅)放宽：
    · M1/M2 → >20%排除（原规则）
    · M3    → >25%排除，板块TOP30%放宽到30%
    · M4    → >35%排除，板块TOP20%放宽到40%

    附加硬规则（所有模式通用）：
    · 同行业不超过1只
    · 同板块取5日涨幅TOP3个股（板块龙头优先）
    · 🔺新晋强势板块候选+1分，🔻退潮板块候选-1分 ★V6.1新增★
    · 梯队定位：同评分下龙头优先、补涨排最后 ★V6.1新增★
    · 仓位修正：position_modifier<1时仓位减半或禁止 ★V6.1新增★
    · 跨策略同行业去重：S1/S2/S3合并后同行业只留最高分 ★V6.1新增★

    ══ S1 评分门槛（原V3蓄力候选） ══

    【第A步：前置过滤 F1-F5】
        逐项检查5个硬条件，不满足4项以上 → 直接淘汰，告知用户原因
        特别注意 F4 回撤范围已收窄为 5%~20%

    【第B步：板块排名检查（V8·强板块准入）】
        查 sector_daily 表，该股所属行业5日动量排名
        → 不在当前模式的板块准入线内 → 直接淘汰，告知："该股所属XX行业排名不在前N%，V8规则淘汰"
        → 在准入线内 → 通过

    【第C步：16分制逐项评分（V8精简版）】
        必须输出完整评分表：
        ① 缩量(0~3) ② 波动收敛(0~5) ③ 板块排名(0~3)
        ④ 红绿交替(0~2) ⑤ 筹码结构(0~3) = 总分/16
        
        → A级 ≥13分 → 推荐，满仓位(1/4资金)
        → B级 11-12分 → 推荐，半仓位(1/8资金)
        → ≤10分 → 不推荐（"评分≤10分，V8规则不入选"），只做观察池展示

    【第D步：排除项检查 X1-X8（V8扩展版）】
        8条排除项逐项检查，踩中任一 → 直接淘汰
        V8新增：X6放量滞涨、X7缩量反弹、X8逼近套牢密集区

    ══ S2 评分门槛（大阳后缩量横盘） ══

    【第A步：前置过滤 F1-F6】
        逐项检查6个硬条件（市值30-300亿、近5日有大阳≥4%+收阳+放量1.5x、
        大阳后缩量<70%、价格≥大阳开盘价、现价>MA60、板块在准入线内）
        不满足 → 直接淘汰

    【第B步：排除项 X1-X6（V8扩展版）】
        大阳后单日跌>3%、放量砸盘、近5日换手>8%、停牌/ST、放量滞涨、逼近套牢密集区 → 踩中淘汰

    【第C步：8分制逐项评分】
        ① 缩量程度(0~2) ② 价格守住(0~2) ③ 板块强度(0~2) ④ 均线配合(0~2)
        → A级 ≥7分 → 推荐，仓位1/4
        → B级 = 6分 → 推荐，仓位1/8
        → ≤5分 → 不推荐

    ══ S3 评分门槛（放量突破新高） ══

    【第A步：前置过滤 F1-F6】
        逐项检查6个硬条件（市值30-300亿、收盘>20日最高、量比≥1.5x、
        收阳、现价>MA20>MA60、板块前50%）
        不满足 → 直接淘汰

    【第B步：排除项 X1-X6（V8扩展版）】
        今日涨>7%、近5日涨>20%、换手>10%、缩量突破、逼近套牢密集区、停牌/ST → 踩中淘汰

    【第C步：6分制逐项评分】
        ① 突破幅度(0~2) ② 放量程度(0~2) ③ 板块力度(0~2)
        → A级 ≥5分 → 推荐，仓位1/4
        → B级 = 4分 → 推荐，仓位1/8
        → ≤3分 → 不推荐

    ══ 三策略并行仓位总控 ══
    · 单只个股最大仓位 = 总资金的1/4
    · 总持仓上限 = 总资金的3/4（即最多同时持有3只）
    · 同策略不超过2只（S2选了2只就不再选S2的B级票）
    · 同行业不超过1只

    ❗ 用户让我"推荐尾盘买入的股票"时（方案B·尾盘当日模式）：
       · 先跑第1步（大盘）+ 第2步（板块）确定方向
       · 再用实时数据扫描候选（三策略并行：S1蓄力+S2大阳横盘+S3突破）
       · 每只候选必须走完对应策略的 A→B→C 评分门槛才能推荐
       · 达标票额外确认「尾盘三项」：
         ① 今日量能确认：今日量 vs 昨日量，量比>1.2有资金进场
         ② 收盘位置确认：现价在今日K线上半段（收阳或上影短）
         ③ 板块内同步：同板块至少2只票今日同方向表现
         → 三项至少满足2项才推荐尾盘买入
       · 尾盘模式仓位减半（A级→1/8，B→1/16）
       · 不达标的也列出来，标注"❌ 不达标：原因"
       · 最终只推荐达标的票，附完整评分表

    ❗ 用户让我"收盘后选股"时（方案A·标准D0→D1模式）：
       · 运行 offline_screener.py 自动扫描 S1+S2+S3 三策略候选
       · 每只候选已通过对应策略评分门槛
       · 达标票标注板块内相对强弱排名
       · 给出次日买入区间、止损位、止盈位、仓位（A级1/4，B级1/8）
       · 同行业只推最高分1只
       · 不达标的也列出来标注原因

    ❗ 用户点名让我分析某只股票时：
       · 正常做深度分析（技术面+资金面+消息面）
       · 分析完之后，额外输出"多策略评分"板块
       · 依次尝试S1/S2/S3三种策略的评分门槛，取得分最高的策略
       · 如果三个策略都不达标，明确告知："深度分析完成，但该股S1/S2/S3均不达标，不建议按短波策略买入"
       · 不达标≠不能分析，但必须标注风险


三、分析输出格式（深度研判标准模板）
═══════════════════════════════════════════════════════════════

    每次输出分析时，按以下结构组织：

    1. 📊 最新数据快照
        当前价、涨跌幅、成交量、换手率、外/内比、五档盘口

    2. 🌍 市场环境

九、操作建议一致性检查（防止矛盾/不可执行建议）
═══════════════════════════════════════════════════════════════

    ❗ 每次输出"操作建议"之前，必须自我检查以下逻辑一致性。
    ❗ 出现任一矛盾 → 修正后再输出，不允许带矛盾的建议交给用户。

    【规则1：买入价必须在买入区间内】
        · 如果建议"等涨到X再买"，X必须 ≤ 买入区间上沿
        · 如果X > 买入区间上沿 → 说明涨过头了，正确建议是"放弃"或"调整区间"
        · 错误示例：买入区间16.99~17.69，但建议"站回17.9再买" → 矛盾！
        · 正确做法：区间内就可买，超出区间就是追高，二选一

    【规则2：等待条件不能否定当前信号】
        · 如果评分已达标（如S2-A级），不能额外加没有依据的"再观察"条件
        · 达标=可执行，给出明确的入场条件（现价在区间内 → 可买）
        · 如果确实有担忧（如日内偏弱），用仓位控制（先1/8）而不是"不买"

    【规则3：风险提示不能和结论互相否定】
        · 如果结论是"推荐买入S2-A级"，风险提示可以说"注意仓位控制"
        · 但不能说"今天不建议买" → 那等于推翻了结论
        · 如果风险足够大到"不建议买" → 那就直接改结论为"不推荐"

    【规则4：止损/止盈必须和买入价匹配】
        · 止损位 < 买入区间下沿（否则还没买就触发止损）
        · 止盈1 > 买入区间上沿（否则一买就该卖）
        · 盈亏比检查：(止盈1 - 买入中位) / (买入中位 - 止损) ≥ 1.5

    【规则5：时间条件不能自相矛盾】
        · "等回踩" + "今天不买明天看" → OK（一致）
        · "等回踩" + "现在就可以买" → 矛盾！ 到底等不等？
        · 正确做法：分场景给if-then（"若回踩到X→买；若不回踩→放弃"）


十、事实核验与反瞎说规则（2026-05-09新增·最高优先级）
═══════════════════════════════════════════════════════════════

        ❗ 本节优先级高于所有分析模板。凡是数据、题材、支撑压力、强弱分类，只能基于可核验来源输出。
        ❗ 如果没有拿到可靠数据，必须写"无法核验/数据不足"，禁止用印象、猜测、单一盘口现象硬编结论。

        1）行情基础字段核验（防止把低开说成高开）
                · 任何"高开/低开/平开"判断，必须显式用：开盘价 vs 昨收价。
                    公式：开盘涨跌幅 = (open / prev_close - 1) × 100%。
                · open > prev_close → 高开；open < prev_close → 低开；误差≤0.05%才可说平开附近。
                · 输出时必须写出关键数值，例如："上证开4163.85，昨收4180.09，低开-0.39%"。
                · 禁止用"今日收盘贴近高点"、"指数上涨"等替代开盘判断。

        2）支撑/压力位判定规则（必须区分候选位与有效位）
                · 支撑/压力的定义：支撑是价格下跌时买盘曾经有效承接的区域；压力是价格上涨时卖盘曾经有效压制的区域。
                · 候选来源按证据强弱排序：
                    ① 多次触碰并反弹/回落的前高前低（至少2次触碰更可靠）
                    ② 放量突破/跌破后的回踩确认位（原压力变支撑，原支撑变压力）
                    ③ 成交密集区/筹码密集区/VWAP附近
                    ④ MA5/MA10/MA20/MA60等均线（只能叫"动态均线参考位"，不能天然等同有效支撑）
                    ⑤ 整数关口（只能叫心理位，必须有价格反应才升级为压力/支撑）
                · 输出必须给"证据等级"：
                    A级：多次触碰 + 放量/缩量验证 + 最近仍有效；
                    B级：前高前低/均线/缺口中至少两项共振；
                    C级：单一均线或单一整数位，只能作为观察位。
                · 不允许把"20日高/低"机械当作唯一压力/支撑；若20日高低与现价方向不匹配，必须剔除。
                · 对次日交易建议，优先使用"区间"而非单点：支撑区/压力区，并说明跌破/突破的确认条件。

        3）题材、行业、概念归属核验（防止错归类）
                · 个股所属题材必须至少有一个可核验来源：
                    ① stock_industry数据库/板块脚本输出；② 行情软件概念/行业接口；③ 公司主营业务/公告；④ 用户提供的明确题材。
                · 不能只因股价同涨同跌，就把个股归入某题材。
                · 若数据库为空、接口失败、或无法确认，必须写："题材归属未核验，不纳入该题材结论"。
                · 错误示例警戒：东阳光不能在未查行业/主营前直接归为"有色金属"；必须先核实其行业/概念。
                · 板块强弱必须使用同一分类口径，不能把"申万行业、概念题材、产业链、自定义主题"混在一张排名里直接比较。

        4）题材轮动定义与判定规则（禁止把随机涨跌说成轮动）
                · 题材轮动 = 存量/增量资金在不同题材之间迁移，表现为：旧主线降温，同时新方向持续获得涨幅、成交额、涨停/核心股强度的接力。
                · 必须同时检查四类证据，至少满足3类才可判断"轮动到XX"：
                    ① 板块排名连续2-3日上升，而旧主线排名下降；
                    ② 板块成交额/换手相对前5日放大；
                    ③ 板块内≥3只个股同步走强，且有1只核心票明显领涨；
                    ④ 涨停/连板/趋势核心出现接力，而不是单日孤立上涨。
                · 单日top5只能叫"当日异动"，不能直接叫"轮动主线"。
                · 单只股票涨停只能叫"个股强"，除非板块内多股共振，否则不能上升为题材结论。

        5）均线位置核验（防止说破线但实际没破）
                · 任何"破5日/10日/20日线"结论，必须写出：收盘价、MA值、偏离百分比。
                    公式：偏离 = (close / MA - 1) × 100%。
                · close > MA 且偏离>+0.5% → 在线上；close < MA 且偏离<-0.5% → 破线；±0.5%内才叫贴线。
                · 禁止只看日内大跌就说"破位"；破位必须对应具体价位或均线。
                · 若是放量长阴但仍在MA5上方，只能说"高位放量分歧/卖压重"，不能说"跌破MA5"。

        6）结论证据标签
                · 每条重要判断后标注证据状态：
                    【已核验】= 有脚本/行情/数据库数值；
                    【部分核验】= 有行情但缺行业/资金等关键维度；
                    【待核验】= 只是推测，不能作为操作依据。
                · 没有数据的内容必须降级为"假设/观察点"，不得用肯定语气。

        7）输出前强制自检清单
                · 我是否把 open 和 prev_close 比过了？
                · 我是否把题材归属查过来源，而不是凭印象？
                · 我是否把支撑/压力写成了有证据等级的区间？
                · 我是否把单日异动误写成轮动主线？
                · 我是否对每个"破线/在线上"写了 MA 数值和偏离？
                · 如果任一项没做到，必须先补数据或改成"无法确认"。
