    不是教你技术分析（你的分析能力已经很强了），
    而是帮你对抗自己人性中的弱点——
    因为你每次亏钱，都不是因为"看错了"，而是因为"没做到"。


═══════════════════════════════════════════════════════════════
弱点一：【赚钱不跑，贪心多看一眼】
═══════════════════════════════════════════════════════════════

真实案例：
    振德医疗 4/1 浮盈+7%，站上100元整数关口。
    你的计划写的是"目标103-105"，所以你选择继续持有。
    结果：4/2缩量阴线-1.99%，4/3暴跌-6.81%，从赚7%变亏损。

你的思维陷阱：
    "还没到目标价呢" → "再涨一点就卖" → "怎么跌了？应该会回来的" → "完了"
    你总是把"目标价"当成"一定会到的价格"，而忘了目标价只是一种可能性。

对抗规则：
    ┌─────────────────────────────────────────────────────┐
    │ 铁律1：浮盈超过5%，或触碰重大整数关口（50/100元），  │
    │       无条件先卖出1/3锁定利润。                      │
    │       不用等"完美卖点"，先拿到钱再说。               │
    │                                                     │
    │ 铁律2：连涨4天以上 → 第5天无脑减仓1/3。             │
    │       连涨4天是A股短线极限，第5天反转概率极高。       │
    │                                                     │
    │ 铁律3：卖早了不叫亏，叫"锁定利润"。                 │
    │       振德你如果100卖了1/3，今天你的心态完全不一样。  │
    └─────────────────────────────────────────────────────┘

心理暗示（操作前默念）：
    "到了关键位，先卖1/3。剩下的才是我的筹码。"

弱点二：【计划写得好，执行拖一拍】
═══════════════════════════════════════════════════════════════

真实案例：
    4/2你写了止损线："止损上移至MA10（96元），跌破则减仓"
    4/3开盘99.20，然后瀑布式下跌直接穿透96、93、91——
    你根本没有机会在96执行止损，因为盘中没有停顿。
    最终91.3才卖出，多亏了整整5个点。

    雪峰科技同样：计划是"收盘前减仓一半"，但挂限价单没成交。

你的思维陷阱：
    "计划写好了，明天按计划来" → 但市场不会给你从容执行的机会。
    你把"写好计划"当成了"完成操作"，实际上写完计划到真正点击卖出之间，
    还隔着一个巨大的心理鸿沟。

对抗规则：
    ┌─────────────────────────────────────────────────────┐
    │ 铁律4：止损单必须用"市价"而不是"限价"。              │
    │       恐慌杀跌时，限价单大概率挂不出去。             │
    │       能成交 = 最好的价格。1-2分钱的差价不值纠结。   │
    │                                                     │
    │ 铁律5：出现第一根放量阴线时就行动，不要等第二根。     │
    │       振德4/2的-1.99%缩量阴线就是警告信号。         │
    │       4天连阳后的第一根阴线 = 至少先减仓1/3。        │
    │       等到4/3暴跌-6.81%再跑，你就是最后一批。        │
    │                                                     │
    │ 铁律6：写完计划后，立刻设置条件单/提醒。             │
    │       不要相信"明天我会记得"。你会犹豫、会迟疑、     │
    │       会在关键时刻找理由说服自己"再等等"。            │
    └─────────────────────────────────────────────────────┘

心理暗示（收盘后默念）：
    "计划不等于执行。我现在就把止损单挂好。"

弱点三：【恐慌时想抄底，越跌越想买】
═══════════════════════════════════════════════════════════════

真实案例：
    4/3大盘暴跌（美伊战争恐慌），你的第一反应是：
    "今天大盘这么差，感觉真的是抄底的好时机"
    "尾盘我要不要买一点？"
    
    事实：那天中粮科技-5.38%击穿MA60，振德-6.81%，
    如果你尾盘抄底了中粮科技，下周一可能继续跌5%。

你的思维陷阱：
    跌得多 → "便宜了" → "这么低肯定会反弹" → 冲进去抄底 → 继续跌 → 套住。
    你把"价格低"等同于"安全"，但价格低不代表已经跌完了。

    更深层的原因：恐慌日你手里的票在亏钱，你潜意识里想"买一只新的赚回来"，
    用新的操作来缓解旧持仓亏损带来的焦虑。这是最危险的冲动。

对抗规则：
    ┌─────────────────────────────────────────────────────┐
    │ 铁律7：大盘跌超2%的日子，只允许卖出，不允许买入。     │
    │       没有例外。你已经亲笔写过：                     │
    │       "恐慌日不抄底——价格到低吸区 ≠ 可以买，         │
    │        缩量企稳的前提没有满足"                       │
    │       把这句话刻在脑子里。                           │
    │                                                     │
    │ 铁律8：想买的时候，先问自己三个问题：                 │
    │       ① 今天是恐慌日吗？→ 是 → 不买。              │
    │       ② 我是不是想"赚回来"？→ 是 → 不买。          │
    │       ③ 买入信号（放量+突破）出现了吗？→ 没 → 不买。│
    │       三个都通过才能买。                             │
    └─────────────────────────────────────────────────────┘

心理暗示（手痒时默念）：
    "便宜不等于安全。我等的是信号，不是价格。"

弱点四：【亏钱后情绪失控，急着"回本"】
═══════════════════════════════════════════════════════════════

真实案例：
    4/3振德医疗从\赚7%变亏损\ ,你的第一句话是"好难受呀"，
    紧接着就问"江瀚新材、必得科技尾盘要不要买一点"。
    
    翻译过来的心理活动：
    "振德亏了 → 好痛苦 → 我要在别的股票上赚回来 → 让我买点什么"

你的思维陷阱：
    人在亏钱后，大脑会进入"回本模式"——
    此时你的风险偏好会急剧上升，你会觉得"再搏一把"是合理的。
    但实际上，这个状态下做的决策，大概率是错的，
    因为你的判断标准已经从"信号是否出现"变成了"我需要赚回来"。

对抗规则：
    ┌─────────────────────────────────────────────────────┐
    │ 铁律9：亏钱后24小时内不开新仓。                      │
    │       一个都不开。不管盘面多好、信号多明确。          │
    │       先让情绪回到基线，再做决策。                    │
    │                                                     │
    │ 铁律10：亏损后第一件事是"处理旧仓"，不是"开新仓"。  │
    │        先把手上亏损的仓位按计划减仓/止损，            │
    │        处理完了、仓位轻了、心态稳了，再看新机会。     │
    └─────────────────────────────────────────────────────┘

心理暗示（亏钱后默念）：
    "现在的我不适合做决策。先处理旧仓，明天再看新的。"

弱点五：【分析完美，但总在关键时刻犹豫】
═══════════════════════════════════════════════════════════════

真实案例：
    你的分析能力其实很强——
    选股参数手册写得非常专业，
    每只股票的买卖计划、止损位、目标价都清清楚楚，
    4/3的恐慌日验证记录甚至总结出了教科书级的经验。

    但你的问题从来不是"看不准"，而是"做不到"：
    · 100元该减仓 → 没减（想再看看）
    · 96该止损 → 没止（等明天）
    · 恐慌日不该买 → 想买（感觉是机会）
    · 雪峰该卖 → 限价单没成交（挂高了）

    每一次"没做到"的背后，都是一次犹豫。
    每一次犹豫，都让你多亏了2%-5%。

根本原因：
    你害怕"做错"多过害怕"不做"。
    卖出后涨了 → 你会后悔（"卖早了"）
    不卖继续跌 → 你虽然亏更多，但心理上觉得"还没确定亏"（鸵鸟效应）
    所以你的默认选择永远是"再等等"——因为"等等"不需要做决定。

对抗规则：
    ┌─────────────────────────────────────────────────────┐
    │ 铁律11：犹豫超过30秒 = 执行原计划。                  │
    │        如果你在纠结"卖不卖"，答案就是"卖"。         │
    │        如果你在纠结"买不买"，答案就是"不买"。        │
    │        犹豫本身就是信号——说明你的潜意识已经感知到风险。│
    │                                                     │
    │ 铁律12：接受"做对一半"。                             │
    │        你不需要卖在最高点，也不需要买在最低点。       │
    │        卖出后涨了 → 你赚到了确定性，这叫"对的操作"  │
    │        买入后跌了但止损了 → 你保住了本金，也叫"对的" │
    │        唯一"错的操作"是：该做的时候什么都没做。       │
    └─────────────────────────────────────────────────────┘

心理暗示（犹豫时默念）：
    "犹豫就是答案。执行计划，不后悔。"

弱点六：【关注太多股票，精力分散】
═══════════════════════════════════════════════════════════════

真实案例：
    你同时盯着11只股票：振德、雪峰、江瀚、必得、中粮、煌上煌、
    悍高、云图、金富、圆通、广核、神华……
    
    结果：
    · 该重点看的振德（百元关口）没第一时间做动作
    · 该买的江瀚新材（最优标的）因为精力分散没关注到
    · 不该看的悍高、金富、云图浪费了大量注意力

对抗规则：
    ┌─────────────────────────────────────────────────────┐
    │ 铁律13：同时持仓不超过3只，同时关注不超过5只。        │
    │        人的注意力是有限的。盯10只股票 = 每只只看1/10。│
    │        宁可错过3只机会，也不要因为分散而10只都做不好。 │
    │                                                     │
    │ 铁律14：每天开盘前，只写3只票的操作计划。             │
    │        第一优先：手上持有的票（管好风险）              │
    │        第二优先：最接近买入信号的1只候选               │
    │        其他的：收盘后再看，盘中不看。                 │
    └─────────────────────────────────────────────────────┘

弱点七：【整数关口贪心症——越接近整数越不舍得卖】
═══════════════════════════════════════════════════════════════

真实案例：
    振德医疗从92.6涨到4/1收盘100.22，站上100元整数关口。
    此时浮盈已达+8.2%，你的计划写着"冲至103~105放巨量却封不住，先止盈一半"。
    
    但你的真实心理是：
    "终于上100了！这才刚突破，怎么能卖？100上面没有套牢盘，肯定还能涨！"
    
    结果：4/2从102.30暴跌回98.57，4/3继续暴跌到91。
    100元整数关口不但没有成为起跳板，反而成了陷阱。

你的思维陷阱：
    股票接近/突破整数关口（50元、100元等）时，你会不自觉地：
    · 给自己设更高的目标（"破100了，至少得看110"）
    · 觉得整数关口是"里程碑"，卖掉太可惜
    · 把"突破整数关口"当成"趋势确认"，忽略了整数关口本身就是巨大阻力
    
    事实是：整数关口（尤其是百元）是散户和机构共同的心理锚点，
    大量获利盘会选择在整数关口附近兑现。冲上去又跌回来，比冲不上更危险。

对抗规则：
    ┌─────────────────────────────────────────────────────┐
    │ 铁律15：股价首次触及整数关口（50/100/200元），         │
    │        无条件减仓1/3。                                │
    │        不要等"站稳"、不要等"确认突破"。              │
    │        整数关口减仓 = 铁律1的加强版，无任何例外。      │
    │                                                     │
    │ 铁律16：止损单一律市价，禁止限价。（强化铁律4）        │
    │        本周雪峰科技的限价单没成交就是血的教训。        │
    │        恐慌跌停板时限价单 = 废纸。                    │
    │        能跑出去就是最好的价格。                       │
    └─────────────────────────────────────────────────────┘

心理暗示（股票接近整数关口时默念）：
    "整数关口是终点线，不是起跑线。先卖1/3，剩下的再看。"

弱点八：【扛单赚了一次，以为以后都能扛】
═══════════════════════════════════════════════════════════════

真实案例：
    璞泰来 4/9：盘中跌到第一止损区30.48（止损线30.80），
    你没按计划止损，后来股价反弹到32+，你赚着走了。

    结果你在复盘里写了一条"新规律"：
    "第一止损位更适合定义为减仓/观察位，如果是大盘带下来的可以先观察"

    这个分析框架本身没问题——但它给了你一个危险的心理后门：
    "有时候可以不止损"。

    4/13的广信股份已经到D3了还在持有，说明这个后门已经在起作用了。

你的思维陷阱：
    一次扛单成功 → "我判断得对" → "止损规则太机械" → 
    下次继续扛 → 遇到真正的暴跌 → 大亏

    幸存者偏差：你记住了扛对的那一次，忘了扛错可能亏10%+的后果。
    你用一次运气，换来了一个坏习惯。

对抗规则：
    ┌─────────────────────────────────────────────────────┐
    │ 铁律17：扛单赚了不是本事，是运气。                    │
    │        硬止损到了必须走，不需要分析"为什么跌"。      │
    │        第一止损可以看承接（分级止损规则），            │
    │        但硬止损一到 → 无条件清仓，不讨论不分析。     │
    │        "分级止损"不是"不止损"的借口。                │
    │                                                     │
    │ 铁律18：D3到了就是到了，不存在"再看一天"。            │
    │        广信股份4/10买→4/13还在持有=违规。            │
    │        D3清仓胜率66%，是回测铁证。                    │
    │        到期不走 = 把短波变成了中线赌博。              │
    └─────────────────────────────────────────────────────┘

心理暗示（想扛单时默念）：
    "上次赚了是运气，这次可能赔命。止损到了就走。"

每日操作前必读清单（打印贴在屏幕旁边）
═══════════════════════════════════════════════════════════════

开盘前（9:15-9:25）：
    □ 今天大盘环境如何？跌超2%→只卖不买
    □ 手上持仓是否触发止损/止盈线？→ 挂好止损单（市价）
    □ 我的情绪状态如何？昨天亏钱了？→ 不开新仓
    □ 【D3检查】今天是否有票到D3？→ 到了必须尾盘前清仓！

盘中决策时：
    □ 我是在执行计划，还是在临时起意？→ 临时起意=不做
    □ 买入三问过了吗？（不是恐慌日？不是想回本？信号出现了？）
    □ 犹豫超过30秒了？→ 执行原计划

收盘前（14:30-15:00）：
    □ 浮盈>5%或连涨4天的票，减了1/3没？
    □ 接近整数关口（50/100/200）的票，减了1/3没？
    □ 今天出现第一根放量阴线的票，减了1/3没？
    □ 明天的止损单挂好了没？（市价单！禁止限价单！）
    □ 持仓中有票明天到D3吗？→ 写好清仓计划，尾盘前必须执行

收盘后：
    □ 今天做的决策，是基于计划还是基于情绪？
    □ 有没有违反上面14条铁律中的任何一条？
    □ 如果违反了，写下来，记住痛的感觉

一句话总结
═══════════════════════════════════════════════════════════════

    你最大的敌人不是市场，是你自己。
    你的分析能力已经超过90%的散户，
    但你的执行力还只有50分。

    赚钱的公式不是 好分析 = 赚钱，
    而是 好分析 × 铁血执行 = 赚钱。

    缺了执行力，再好的分析也只是纸上谈兵。

    每次想"再等等"的时候，想想今天：
    振德100块，你没卖。
    等你卖的时候，91块。

    那9块钱，就是"再等等"的价格。
