0）所有股票问题的总前置规则（防AI乱说）
═══════════════════════════════════════════════════════════════

无论我问早盘、竞价、尾盘、收盘、点名分析还是持仓诊断，请先执行：
1）读取并遵守《交易体系/AI分析防臆想规则.md》和《交易体系/分析规范.txt》。
2）先跑/检查对应模块的数据，再输出观点：
   · 股票短波：market_mode.py → em_board_rotation.py(找主线/退潮三级行业) → offline_screener.py(选股主流程，概念阶段=东财三级行业轮动档) → 实时行情核验
   · 持仓诊断：先拉实时行情，再对照交易记录和原计划
3）输出必须分清：事实、推断、不确定。
4）任何操作建议必须带：证据、反证条件、执行价位、仓位、置信度、下一触发条件。
5）关键数据缺失时，不准硬给买入结论，只能给观察/等待/无法判断。
6）明确建议交易后，尽量记录到 trade_log.py 或当日复盘，后续检查次日/3日/5日表现。

买点触发但大盘同步转弱时，必须先套用【大盘转弱二次确认规则】：
1）普通候选硬否决：任一主要指数跌幅扩大到-1%以上、情绪/模式转为M5或退潮、尾盘指数快速跳水、候选所属板块/概念同步转弱、个股放量跌破买入区间或关键位 → 当日放弃。唯一例外是 `offline_screener.py` 明确标✅的T5技术主线狙击票，按脚本仓位执行（优先1/12、降权1/16）；未标✅不得主观放行。
2）轻中度转弱默认等二次确认：大盘从强转弱但未触发硬否决时，不因恐惧直接取消，也不立即买入；等待10-15分钟或等尾盘确认。
3）二次确认通过才降仓执行：至少满足“指数跌幅收敛或站回分时均线、候选仍在买入区间/关键位上方、板块/概念前排仍有承接、个股不是放量砸盘”中的3项 → 原计划仓位×0.5执行；若本来就是试探策略，则继续按试探仓，不得加仓。
4）二次确认失败：转为观察/放弃，并在复盘中记录“买点触发但大盘转弱，按规则暂停”，不能事后因拉回而归因成执行错误。

通用输出尾部必须追加：
【胜率-赔率-确定性】胜率感 / 赔率 / 确定性 / 置信度
【反证条件】什么情况说明本次判断错了
【执行纪律】今天最多能买几只、总仓位上限、不能追高的位置
【价格区间执行·手动版(观察期，2026-07-01起)】——尾盘/收盘选出票后按此执行，先手动跑顺再固化进脚本：
  · 追高上限：现价高于买入区上沿+3%一律不买，宁可错过；系统标“等回踩”的票回踩不到就放它走，记“错过”不记损失，绝不追顶。
  · 分批止盈：别死等+4%。到最近压力位、或+2~2.5%先卖一半落袋；剩下用“从当日最高回落就走”跟(移动止盈为主，不是等固定目标)。
  · 止损看收盘：硬止损用收盘价判定，别被盘中影线洗出；高波动票(半导体/科创等)本就该给更宽止损→改成减半仓进、把单笔亏损金额压住；另设盘中-6%熔断防黑天鹅。

给专业人士检查系统时，先打开《交易体系/专业分析师检查清单.md》，按清单逐项审查数据、规则、风控和复盘闭环。

0.2）走势概率 + 分情景应对（通用输出块·选股/点名必挂，唯一定义在此，别处只引用）
═══════════════════════════════════════════════════════════════
（推荐每只票时都挂这一段。概率=“当前证据下的主观胜率感”，不是事实，缺数据写“无法定概率”。
 词汇必须与脚本对齐：市场模式=M1-M5；情绪周期只用 冰点/修复/发酵/高潮/分歧/退潮/过热；
 行业档位只用 持续主线/上升轮动/强势板块/普通轮动/退潮/—；买点只用 可买/小仓/等回踩/等确认/仅观察。）

① 大盘走势研判 + 概率
【大盘结论】今天大盘更像 修复 / 震荡 / 退潮 —— 一句话。
【概率三分】修复(转强) __% ｜ 震荡(横盘) __% ｜ 退潮(转弱) __%   （三者相加=100%）
【判定依据】照抄 market_mode.py 的值，不许编：
  · 市场模式 M__（composite综合情绪=__/10：上证0.3+深证0.3+创业板0.4）；情绪周期=__(得分__/12)
  · 仓位修正器 position_modifier：1.0正常 / 0.5减半(高潮·分歧) / 约0.33=M5技术主线例外风险档 / 0=过热禁开仓
  · 创业板：站/破 MA60、MA20>MA60?、近5日涨幅__%；涨停生态：涨停家数/连板高度/炸板率(有则写)
【概率锚点】(把模式映射成概率区间，再按情绪/涨停生态微调±10~15%)
  · M4强趋势 或 情绪=发酵：修复≥55 / 震荡25~35 / 退潮≤15
  · M3反弹：修复40~50 / 震荡30~40 / 退潮15~25
  · M2震荡：修复25~35 / 震荡40~50 / 退潮20~30
  · M1磨底：修复20~30 / 震荡40~50 / 退潮25~35（冰点则上调修复、可S1蓄力）
  · M5 或 情绪=高潮/分歧/退潮/过热：退潮≥45，偏防守；过热直接判“今日不新开仓”；退潮只允许T5全条件通过者小仓
  · 微调：涨停萎缩+炸板率升→退潮+10；缩量企稳/首板高度提升→修复+10

② 本股所在行业走势研判 + 概率
【行业档位】本股行业「____」当前档=__（持续主线/上升轮动/强势板块/普通轮动/退潮/—），
            sector_rank 5日动量分位=__，在 rotation_rising/falling 哪边、rot 标记(🔺/🔻/无)。
【行业概率三分】走强(延续/加速) __% ｜ 维持(轮动分歧) __% ｜ 走弱(退出轮动) __%  （相加=100%）
【档位映射】(与脚本 _industry_stage_bonus 一致)
  · 持续主线(rotation_rising且分位≥0.8,+2)：走强≥55，回调=低吸而非退潮
  · 上升轮动(rotation_rising不足0.8,+1)：走强45~55，看能否升主线
  · 强势板块(分位≥0.85,+1)：走强40~50，易一日轮动→维持概率高
  · 普通轮动(0)：走强≤30，不作主攻方向
  · 退潮(rotation_falling)：走弱≥50，只超跌反抽快进快出或回避
  · —(无行业)：不定概率，不作行业加分

③【分情景应对】大盘 × 行业 → 观察本股信号 → 操作
（只展开概率最高的2~3个组合，别写满9宫格。每个情景给：触发条件→看本股什么信号→做什么动作。
 动作只用 可买/等回踩/小仓/减仓/清仓/放弃；价位纪律照 0)节【价格区间执行·手动版】。）

▶ 情景A：大盘修复 × 行业走强（顺风，进攻）
  看本股信号(≥2项才动手)：①量比>1.2且收阳/上影短、收在K线上半段，非放量滞涨(X6)/缩量假反弹(X7)
   ②站稳分时均线、回踩不破开盘/VWAP、尾盘不跳水 ③本股强于行业指数、梯队前排(龙头优先)
   ④现价在脚本买入区间内、未破关键位(S4的MA5 / S1的MA20/MA60 / S3的突破位 / S2的大阳开盘)
  操作：· 买点=可买且现价≤区上沿 → 按模式仓位执行(主力A级1/4·B级1/8；试探仅A级、按position表缩；pos_mod<1再×0.5)
   · 买点=等回踩 → 挂回踩区0~+3%以内等；回踩不到→放弃记“错过”，绝不追顶
   · 买点=等确认(现价<区下沿) → 等放量站回区间再动，别抄早

▶ 情景B：大盘震荡 × 行业走强 / 大盘修复 × 行业维持（半顺，降级试探）
  看本股信号：温和放量非天量、收阳且未到追高线；分时不破均线、同板块≥2只前排同步红；本股+行业均不弱于大盘；守住 MA5/突破位/大阳开盘(破则本情景失效)
  操作：只做 可买/小仓，仓位比情景A再降一档(或×0.5)；优先主力/辅助策略，试探策略此情景可放弃；
   买点触发但大盘震荡时先套【大盘转弱二次确认规则】，满足≥3项才原仓×0.5执行

▶ 情景C：大盘退潮 / 行业退潮（任一退潮，防守·找该不该跑）
  看本股信号：是否放量跌破买入区/关键位(收盘价判定)；是否尾盘跳水、分时均线持续下压；是否比行业/大盘更弱；收盘是否跌破硬止损
  操作：· 未持仓 → 过热一律禁开；退潮/M5普通候选放弃，只有脚本标✅的T5技术主线例外可按脚本小仓
   · 持仓且收盘破硬止损/逻辑失效 → 清仓(止损挂市价)
   · 持仓未破位但大盘退潮 → 减仓：到压力位或+2~2.5%先卖一半，剩余用“日内高点回落2.5%(S4为3%)”移动止盈
   · 普通候选硬否决(任一指数跌>1%、情绪转M5/退潮、尾盘跳水、板块同步转弱、个股放量破位)→ 当日全弃；T5必须继续满足行业逆势强度、放量、板块同步和合法买入区

▶ 情景D(可选，概率分散时)：大盘震荡 × 行业普通/退潮 → “放弃本股，今日无优势”，一句话带过。

0.3）实时盯盘触发（候选进入待命后，只等规则触发，不临场改剧本）
═══════════════════════════════════════════════════════════════

定位：选股/点名分析只负责给出“可以买的计划”；真正下单前，必须用 realtime_guard.py 把候选变成“等待触发”的盯盘单。
realtime_guard 只提示动作，不自动下单；成交后仍用 trade_log.py buy/sell 记录。

启动买入盯盘的前提：候选必须已有完整计划：
  代码 / 策略 / 买入区间 / 硬止损 / 软止损 / 仓位 / 置信度 / 反证条件 / D2或D3周期。
  缺任一项，不启动盯盘，只能先补计划。
状态铁律：形态观察池≠实盘狙击单。每日只有 `offline_screener.py` 输出的“主狙击1只+备用1只”有下单资格；方案A/C只有D0实际成交后才转持仓和D1卖出计划，未成交票当日失效，不结转到竞价重新买。

买入触发优先级：
1）总闸门先判：过热或position_modifier=0 → 全部禁止买入。M5/退潮/任一主要指数跌超-1% → 普通候选禁止；只有计划中已标“T5技术主线例外✅、优先1/12或降权1/16”的票继续判断。
2）价格闸门：高于买入区上沿+3% → 追高放弃；高于上沿 → 等回踩；低于下沿 → 等确认；跌破硬止损 → 原计划失效。
3）账户风险闸门：按“计划仓位 × 从现价到硬止损的亏损幅度”计算，默认单笔账户风险>1.25%禁止买入。
4）入场确认：现价在买入区内，且至少满足2项：收在日内区间上半段、外/内比≥1、现价不低于开盘价、当日跌幅不弱于-1.5%。
5）只有输出“买入触发”时才允许下单；输出“继续等待/等回踩/等确认/禁止买入/追高放弃”时，不准凭感觉抢。

卖出触发优先级（卖出永远高于新开仓）：
1）盘中-6%熔断 → 立刻全清。
2）到D1首次兑现位（最近压力位或买入价+2%~2.5%）→ 卖50%；强势目标保留为S1/S2/S3 +4%、S4 +6%。
3）日内高点回落触发移动止盈：S1/S2/S3回落2.5%，S4回落3% → 剩余全清。
4）D2/D3到期且无有效R1授权 → 14:40后全清；亏损到期票挂市价，不等反抽。
5）尾盘仍低于硬止损 → 全清；低于软止损 → 按计划次日开盘/可成交窗口处理。
6）当前市场转M5/退潮且持仓浮亏 → 先处理旧仓；只有旧仓处理完、账户暴露未超限且T5标✅，才允许脚本给定的小仓新仓。

R1滚动持有授权（只覆盖“已首次兑现后的盈利剩余仓”，不是把短线自动改成长线）：
1）先完成D1首次兑现并用 `trade_log.py cashout ID 成交价 --shares 实际卖出股数` 落库，授权时相对原买入价仍盈利≥2%；未兑现、亏损或只是“感觉会涨”均不得授权。
2）五项逐项给事实证据：market市场、sector板块、relative个股相对强度、price_volume价格/量能、reward_risk剩余赔率。至少4/5，且market、sector、price_volume、reward_risk四项必须通过；下一压力/目标到当前价的空间 ÷ 当前价到保护线的风险必须≥1.5。
3）利润保护线≥原买入价+1%、低于授权时现价，并且以后只能上移不能下移；盘中跌破先观察，14:50仍收不回则剩余仓全清。
4）每次只授权到下一交易日；到期前若证据继续成立可重新签发一次，未续签自动恢复D2/D3默认退出。-6%熔断、逻辑失效、移动止盈和强势目标优先级仍高于R1。
5）R1只管理剩余仓，不授权净加仓。做T只允许先卖后买，回补≤当日已卖数量，收盘仓位不得高于授权前剩余仓；全部卖完后再买算新交易，重新走买入闸门。
6）必须落库，不能口头豁免：
   python 工具脚本/50_交易记录/trade_log.py authorize-hold ID --price 当前价 --protect 保护价 --next-target 下一压力位 --until 下一交易日 --checks market,sector,price_volume,reward_risk --evidence "事实证据" --invalidation "失效条件"

标准对话：
  “盯 002015，按刚才计划等触发买入” → 先复述计划字段，再启动 buy 盯盘。
  “盯 ID=18，明天到触发点提醒我卖” → 用 sell 盯盘；D2/D3默认退出，只有已经落库且仍有效的R1才可覆盖。
