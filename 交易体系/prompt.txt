①a 早盘准备（08:30-09:15，竞价前）
═══════════════════════════════════════════════════════════════

早盘准备：
1）当前持仓有没有到D2/D3必须清仓的？
2）有没有触发止损线的？（硬止损-3%，软止损收盘-1.5%）
3）有没有冲高回落该保本出的？
4）跑 market_mode.py → 判定当前市场模式(M1-M5) + 情绪周期阶段
   · M5极端 → 今天不开新仓
   · 高潮/分歧 → 仓位×0.5
   · 退潮 → 禁止新开仓
5）跑大盘情绪评分，今天适不适合新开仓？
6）生成【竞价观察清单】：
   - 持仓票：列出每只票的关键位（止损位、止盈+4%线），
     标注竞价阶段重点观察什么（低开幅度警戒线、高开是否该止盈）
     标注逻辑失效条件（V8必查：失效就直接走，不等止损）
   - 昨晚候选票（备选方案选出的）：列出每只票昨晚算好的买入区间，
     标注竞价高开多少就放弃（建议>3%放弃，>5%必弃）

→ 输出格式：一张简洁清单，09:15-09:25时对着看就行

①b 竞价确认（09:25-09:30，竞价出结果后）
═══════════════════════════════════════════════════════════════

竞价确认，拉开盘价数据，逐一检查：

【持仓票确认】
1）有没有竞价大幅低开（>3%）的？→ 判断是否需要9:30挂单先出
2）有没有竞价涨停/大幅高开的？→ 是否到止盈位，准备冲高卖出
3）竞价缩量平开的持仓 → 按原计划持有

【候选票确认（昨晚方案A选出的）】
4）候选票开盘价 vs 昨晚买入区间：
   - 开盘价在买入区间内 → ✅ 可执行买入
   - 高开超出区间但<3% → ⚠️ 谨慎，缩减仓位或等回落
   - 高开>3% → ❌ 放弃，不追高
   - 低开>3% → ⚠️ 可能有利空，先观察不急买
5）大盘竞价整体氛围：高开票多还是低开票多？与昨晚情绪评分是否一致？

→ 输出：今日操作计划确认版（哪些买、哪些卖、哪些观望）

①c 早盘选股（纯盘面驱动）
═══════════════════════════════════════════════════════════════

早盘选股。不看以往候选，纯粹从今天盘面出发，扫全市场给我能买的票。

【执行要求】
1）先跑 market_mode.py → 判定市场模式(M1-M5) + 情绪周期
   · M5极端 → 直接停，不选股
   · 高潮/分歧 → 仓位×0.5
   · 退潮 → 禁止开仓
2）大盘快照：三大指数涨跌幅，判断能否开仓（跌>1%不开）
3）按当前模式启用对应策略（不是三策略全开）：
   · M1 → S1为主，S2/S3仅×0.3试探仓
   · M2 → S1+S2为主，S3×0.3试探
   · M3 → S2为主+S3辅助，S1×0.3试探
   · M4 → S3为主+S2辅助，S1×0.3试探
4）全市场实时扫描：
   · 从数据库找近7日有大阳线(≥4%放量)的票
   · 批量拉实时行情，筛选今日涨0.5%~4%且站上MA5的
   · 板块过滤（V8激进版·只看强板块）：
     M1前50% / M2前50% / M3前30% / M4前25%
   · 评分门槛：S1 A≥13/B=11-12(16分制) / S2 A≥7/B=6 / S3 A≥5/B=4
   · 排除项含V8新增：X6放量滞涨、X7缩量反弹、X8逼近套牢密集区
5）梯队定位：同板块优先龙头(前15%)，回避补涨(后50%)
6）同行业去重，只保留最强1只

【输出格式】直接给结论表：

   #  股票  代码  现价  涨幅  策略  评分  板块排名  梯队
   买入价: XX.XX ~ XX.XX（现价或回踩后可接的区间）
   止损: -3%硬止损XX.XX / 收盘-1.5%软止损XX.XX
   止盈: +4%卖50% → XX.XX / 移动止盈(高点回落2.5%全清)
   逻辑失效: XXXXX（到了直接走，不等止损）
   仓位: 1/4 或 1/8（弱势策略×0.3，情绪修正后最终仓位）

   ─ 不超过5只 ─

【一致性规则】（分析规范v2.1）
   · 买入区间必须是当前可执行的价格，不给"等涨到X再买"这种矛盾建议
   · 现价在区间内 → 直接说"可买"；现价超出区间 → 说"放弃"或"等回踩到X"
   · 涨>3%的票标注"已超追高线，放弃"，不要既推荐又说不追

【仓位纪律】
   · 主力策略：A级=1/4仓  B级=1/8仓
   · 弱势策略(非主力)：仓位×0.3（1/12或1/16）
   · 情绪修正：高潮/分歧再×0.5
   · 今天最多新开2只
   · 方案A(尾盘)D0买→D2清 / 方案B(收盘)D1买→D3清

①d 持仓诊断（盘中随时，想确认某只持仓要不要动时用）
═══════════════════════════════════════════════════════════════

持仓诊断 XXXXXX（股票名/代码），成本XX.XX，D几。今天要不要卖？

【执行要求】
1）拉该股实时行情（现价、涨跌幅、日内高低、量能、外/内比）
2）对照我给的成本价，算浮盈/浮亏
3）结合今日盘面（大盘、板块、量价形态）给出结论

【判断逻辑】检查以下条件，命中哪条就执行哪条：
   · 逻辑失效条件触发 → 立即卖，不等止损价！（V8最优先）
     S1：D1放量下跌（不是缩量）→ 洗盘逻辑失效
     S2：量放大到大阳线80%+且收跌 → 主力出货逻辑失效
     S3：次日低开跌回突破位下方 → 假突破逻辑失效
   · 盘中跌破-3% → 硬止损，立即卖，挂市价
   · D2/D3今天到期 → 必须今天清，给建议卖出时段和挂单价
   · 浮盈触及+4% → 卖50%仓位，给挂单价（V8统一止盈1）
   · 剩余仓位：从日内最高点回落2.5% → 全清（V8移动止盈）
   · 冲高回落（日内从高点回落>2%）→ 建议保本出或减仓
   · 以上都没触发 → "不动，继续持有"，说明原因

【输出格式】直接给结论：

   票名  成本XX.XX  现价XX.XX  浮盈+X.X%  D几  策略(S1/S2/S3)
   → 动作：不动 / 卖50% / 全清
   → 挂单价：XX.XX（如需卖出）
   → 逻辑失效条件：XXX（是否已触发）
   → 原因：一句话

【挂单价建议规则】
   · 止盈卖出：给两档 ① 保守价（买一价，立即成交）② 乐观价（日内高点附近，搏回冲）
   · D3清仓：盈利→挂现价-0.02立即走；亏损→挂市价不犹豫
   · 止损卖出：挂市价，不挂限价（铁律16）
