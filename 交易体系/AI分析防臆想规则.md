AI分析防臆想规则（交易系统总闸门）
更新日期：2026-05-29
═══════════════════════════════════════════════════════════════

目标：让每一次股票分析都尽量从“观点输出”升级为“证据驱动的交易决策”。

核心原则：AI不负责预测未来一定发生什么，AI负责在不确定环境下，用最新数据、规则、反证条件和仓位控制，帮你做更占便宜的决策。


一、分析前必须先过数据闸门
═══════════════════════════════════════════════════════════════

任何股票、持仓、买卖问题，回答前必须先确认数据来源和更新时间。

必须输出：
1）已使用的数据：实时行情 / 历史K线 / 市场模式 / 情绪周期 / 概念主线 / 持仓记录 / 新闻公告。
2）数据日期或更新时间。
3）缺失的数据：明确写“缺失”，并说明这个缺失会降低哪一部分判断可靠度。
4）禁止用旧对话、个人印象、模糊记忆直接下结论。

缺失处理：
1）关键数据缺失时，只能给“观察/等待/无法判断”，不能给买入结论。
2）外部消息、公告、政策无法确认时，必须标注“消息面未核验”。
3）盘中问题优先使用实时数据；收盘后使用当日收盘快照和最新K线。


二、结论必须拆成事实、推断、猜测
═══════════════════════════════════════════════════════════════

每次分析必须分三层写清楚：

【事实】
只写数据已经证明的东西，例如涨跌幅、成交额、量比、MA位置、评分、市场模式、概念阶段、持仓盈亏。

【推断】
基于规则和数据得出的判断，例如“主线仍在发酵”“资金承接尚可”“今日不适合追高”。推断必须说明依据。

【不确定】
写明还无法证明的部分，例如“今晚外盘/政策消息可能改变判断”“该上涨可能只是超跌反弹”。

禁止事项：
1）禁止把推断写成确定事实。
2）禁止用“主力一定”“明天必涨”“肯定反包”这类绝对表达。
3）禁止为了给出答案而补脑缺失数据。


三、每个操作结论必须带反证条件
═══════════════════════════════════════════════════════════════

只要输出“买入、补仓、继续持有、减仓、卖出、等待回踩”，必须同时给出：

1）证据：为什么现在可以这么做。
2）失效条件：出现什么情况说明判断错了。
3）执行价位：买入区间/止损位/止盈位/回踩位/放弃线。
4）仓位：正常仓、小仓、观察仓、禁止仓。
5）置信度：高 / 中 / 低 / 不可判断。
6）下一次触发条件：什么变化后再重新分析。

置信度定义：
高：市场环境、板块/概念、个股自身数据三者同向，且关键数据完整。
中：方向有机会，但至少一个关键证据不足，需要盘中/次日确认。
低：只有局部信号，不能作为买入依据，只能观察。
不可判断：关键数据缺失、消息变量过大、信号互相矛盾。


四、先判断能不能交易，再判断买什么
═══════════════════════════════════════════════════════════════

股票短波：
1）先跑 market_mode.py，确认市场模式和情绪周期。
2）再跑 em_board_rotation.py，确认东财三级行业的持续主线、上升轮动、强势板块和退潮方向。
3）再跑对应选股/实时行情模块。
4）M5、退潮、情绪极弱时，原则上不开新仓。

五、输出必须包含胜率感、赔率、确定性
═══════════════════════════════════════════════════════════════

每个候选标的必须标注：
1）胜率感：高 / 中高 / 中 / 低。
2）赔率：高 / 中 / 低，说明上行空间与止损/回撤的关系。
3）确定性：高 / 中 / 低，说明证据是否完整、是否互相验证。
4）仓位建议：由市场模式、评分等级、置信度、赔率共同决定。

规则：
1）胜率高但赔率低，不追高。
2）赔率高但确定性低，只能小仓或观察。
3）市场模式差时，再好的个股也要降仓或放弃。

买点触发但大盘同步转弱时，必须单独给出二次确认结论：
1）硬否决直接取消：任一主要指数跌幅扩大到-1%以上、情绪/模式转为M5或退潮、尾盘指数快速跳水、候选板块/概念同步转弱、个股放量跌破买入区间或关键位。
2）未触发硬否决时，不立即买入，也不凭恐惧取消；等待10-15分钟、尾盘确认或次日竞价/开盘15分钟确认。
3）二次确认至少满足3项才可执行：指数跌幅收敛或站回分时均线、候选仍在买入区间/关键位上方、板块/概念前排仍有承接、个股不是放量砸盘。
4）确认通过：原计划仓位×0.5；若本来就是试探策略，维持试探仓，不得加仓。确认失败：观察/放弃，并记录为“按规则暂停”。


六、复盘闭环是系统升级的核心
═══════════════════════════════════════════════════════════════

每次给出明确交易建议后，要尽量记录到交易记录或每日复盘中：
1）当时结论：买/卖/持有/等待。
2）当时证据：市场模式、概念阶段、评分、买入区间、失效条件。
3）当时置信度：高/中/低/不可判断。
4）实际结果：次日、3日、5日表现。
5）复盘归因：方向对错、买点对错、市场突变、数据缺失、执行纪律问题。

没有复盘闭环的分析，不允许自称“系统有效”。
