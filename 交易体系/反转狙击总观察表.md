# 反转狙击总观察表

更新日期：2026-08-05 10:51  
覆盖方向：玻纤制造、半导体材料、印制电路板、电子化学品、光模块/CPO。  
当前总状态：**M5 过热 / 科技反转雷达仅到 R1 黄色预警 / 无实盘授权 / 禁止提前抢跑**。

> 本表用于持续跟踪，不是静态荐股名单。“弹性”衡量反转成立后的潜在涨幅敏感度；“确定性”衡量业绩与产业证据。真正开仓前，必须依据当日行情另做买入区、止损、仓位和赔率计划。

## 一、狙击流程

```text
市场退出M5
  → 激活一个最强板块
    → 板块核心股联动
      → 个股站回MA20并完成首次回踩
        → 量能与业绩闸门通过
          → 进入待击池，制定实时交易计划
```

纪律：每轮只激活 **1 个主攻板块**；每个板块最多 **3 只待击股**；实际出击最多选择“1只高确定性锚 + 1只高弹性股”。

### 全局硬闸门

| 闸门 | 通过标准 | 当前状态 |
|---|---|---|
| G1 市场 | 市场退出M5；创业板/深成指不再创新低，至少站回MA10，最好进入M3 | ❌ |
| G2 板块 | 对应板块五日相对收益转正，连续3日不弱于大盘，成交量恢复至20日均量附近或以上 | ❌ |
| G3 联动 | 对应板块至少2只核心股同步转强，不能只有一只独涨 | ❌ |
| G4 个股 | 收盘站回动态MA20，首次回踩不破；距MA20超过12%不追 | ❌ |
| G5 基本面 | 财报、价格、订单或产能利用率不低于预期；非经常损益不能冒充主营反转 | 部分通过 |

五道闸门至少通过四道，且 G1、G2、G4 必须通过，个股才能进入“待击”。
