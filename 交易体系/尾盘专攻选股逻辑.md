# 尾盘专攻选股逻辑

> 目标：专门服务 14:40-14:55 当日尾盘买入，D1 持有/止盈，D2 默认退出；只有符合R1的盈利剩余仓可逐日滚动。
> 核心原则：尾盘不是多一个追涨理由，而是用当天已经走出来的数据，减少隔夜猜测和盘中噪音。

---

## 一、尾盘策略定位

尾盘专攻不是独立形态，而是 S1/S2/S3/S4 之上的执行过滤层。

```text
市场模式 → 概念/板块 → S1/S2/S3/S4候选 → 买点状态 → 尾盘确认 → 仓位/执行
```

尾盘只解决一个问题：这只候选今天是否已经满足“可以在收盘前买”的条件。

因此最终结果必须分成四类：

| 状态 | 含义 | 操作 |
|---|---|---|
| 可买 | 价格在买入区间内，尾盘确认达标 | 14:40-14:55 执行 |
| 小仓 | 买点基本达标，但尾盘确认或盈亏比略弱 | 降仓执行或放弃 |
| 等回踩 | 形态好，但价格高于买入区间 | 不追，等回落 |
| 等确认 | 价格低于确认区或未站稳关键位 | 不买，等站回 |
| 仅观察 | 形态、板块、筹码或风险不达标 | 不交易 |

尾盘当天没有“可买”是正常结果，不允许为了交易而降低硬条件。

v7状态分层：

1. **形态观察池**：S1~S4入围票，用于展示和跟踪，不等于下单授权。
2. **实盘狙击短名单**：经价格、盈亏比、尾盘三项、市场闸门和D1延续分后，每日只授权主狙击1只+备用1只。
3. **实际持仓**：只有D0已成交的方案A/C才进入D1卖出管理；备用不与主狙击同时下单，未成交候选当日失效。

方案B独立：D0只产生次日入场候选，D1竞价后才决定是否买；不得与已在D0买入的方案A/C混用。

## 二、时间流程

| 时间 | 动作 | 目的 |
|---|---|---|
| 13:50-14:00 | 更新腾讯实时快照 | 让日K含当天最新价量 |
| 14:00-14:20 | 跑市场模式、概念主线、主筛选器 | 生成候选池 |
| 14:20-14:35 | 对候选做尾盘确认 | 判断可买/等回踩/仅观察 |
| 14:40-14:55 | 只买“可买”票（连续竞价·可自定价） | 避开盘中噪音，减少隔夜时间 |
| 14:55-15:00 | 连续竞价停·收盘集合竞价 | 不在最后几分钟临场追价 |
| 15:00-15:05 | 收盘价定死后再定案一次（**方案C**） | 用最终收盘数据复核候选 |
| 15:05-15:30 | 盘后固定价格按**收盘价**接“盘后可接”票（**方案C·2026-07-06新规**） | 数据100%确定 + 当日无隔夜 + 成交价=收盘价 |

### 方案C·盘后固定价格选股（15:05-15:30，按收盘价当日买入）

2026-07-06 新规：盘后固定价格交易（15:05-15:30，**按当日收盘价成交、时间优先撮合**）扩展到全部A股，主板(00/60)已适用。它填的是方案A(尾盘盘中价买)与方案B(收盘后次日买)之间的空档：**方案B的收盘数据确定性 + 方案A的当日无隔夜 + 成交价=收盘价(独有)**。

- **流程**：14:00-14:57 先按方案A预跑草稿 → 15:01 拉最终收盘快照(`_update_today_snapshot_qq.py`，此刻腾讯现价=收盘价) → 跑 `em_board_rotation.py --window 10 --top 20` 得到【明日优先三级行业 / 降权行业 / 禁入行业】 → 15:01-15:05 重跑 market_mode + offline_screener → 15:05-15:30 挂盘后单。
- **行业预案先行**：明日优先行业才作为主攻方向；降权行业只接前排A级且仓位降一档；禁入行业形态再好也不买。
- **买点变二选一**（盘后只能收盘价成交，不能等回踩）：
  - 收盘价 **≤ 买入区上沿** → **盘后可接**（15:05 一开就挂，时间优先早挂早成）；
  - 收盘价 **> 买入区上沿** → **放弃**（高了就是高了，盘后不将就）。
- **行业档再确认**：明日优先 → 正常排序/原仓位；降权行业 → 只接前排A级且仓位降一档；禁入行业 → 放弃。
- **盘后特有铁律**：① 可能挂不上(固定价+时间优先)→ 想接就 15:05 立刻挂、不成记“错过”不追；② 只认收盘价、不搏差价；③ 涨/跌停票盘后别碰(单边挂不到货)；④ 同日刚卖出的票不当日买回(churn)；⑤ 禁入行业不进候选。
- **时间线**：盘后买 = D0 → D1 持有/止盈 → D2 默认退出（与方案A一致）；已首次兑现且满足R1的盈利剩余仓可显式授权至下一交易日。仓位按模式+情绪修正(分歧×0.5)，不因“价格确定”而加仓；降权行业再降一档。
- **记账**：盘后成交在 `trade_log.py buy/sell --reason` 里标“盘后C”，与方案A/B区分；不单独 bump sysver（选股打分逻辑未变）。

推荐执行命令：

```bash
python 工具脚本/10_数据更新/_update_today_snapshot_qq.py
python 工具脚本/20_市场环境/market_mode.py
python 工具脚本/20_市场环境/em_board_rotation.py --window 10 --top 20
python 工具脚本/30_候选短股/offline_screener.py
python 工具脚本/10_数据更新/tmp_rt.py 候选代码1 候选代码2
```

如果当天快照已写入库，收盘后还需要再跑一次数据更新，避免 14:30 的临时快照覆盖正式收盘数据。

走**方案C**时，15:01 收盘价定死后重跑上面的 快照→market_mode→screener 一遍，用最终收盘价定案，再于 15:05-15:30 按收盘价挂盘后单。

## 三、第一层：市场只控仓，不再关闭候选

尾盘先找强行业和合法买点，再用市场环境决定仓位。大盘不再让候选消失，但极端环境只开放严格的小仓例外。

| 条件 | 结论 |
|---|---|
| M5 极端市 | S1-S4照常扫描A级；普通候选只观察，符合T5例外才可小仓（优先1/12、降权1/16） |
| 情绪周期 = 退潮 | 强制M5；只开放T5技术主线狙击例外 |
| 情绪周期 = 过热 | 禁止开仓，不开放例外 |
| 情绪周期 = 高潮/分歧 | 可筛选，但仓位乘 0.5，只做 A 级 |
| 大盘尾盘快速跳水 | 不开新仓，已有候选转观察 |
| 三大指数至少两只站上 MA20，且综合情绪 >= 5 | 正常进入候选筛选 |

模式对应策略：

| 模式 | 尾盘主攻 | 尾盘辅助 | 低优先级 |
|---|---|---|---|
| M1 磨底 | S1 蓄力启动 | S2 低吸承接 | S3 仅 A 级试探 |
| M2 震荡 | S1/S2 | S4 主线试探 | S3 仅 A 级试探 |
| M3 反弹修复 | S2 大阳后承接 / S4 主线跟随 | S3 放量突破 | S1 仅 A 级试探 |
| M4 强趋势 | S3 放量突破 / S4 主线跟随 | S2 强势整理 | S1 仅 A 级试探 |
| M5 极端 | 技术焦点池A级扫描 | T5逆势强板块例外 | 普通候选仅观察 |

## 四、第二层：板块与概念门控

尾盘买的是“当日资金已经表态”的方向，不买孤立个股。

| 项目 | 达标线 |
|---|---|
| 东财三级行业 | 先用 em_board_rotation.py 锁定【明日优先三级行业 / 降权行业 / 禁入行业】，优先在“明日优先”中选票 |
| 板块强度 | 按 `market_mode.py` 当前准入线：M3 的 S2/S3 必须前 30% |
| 行业阶段 | 持续主线、上升轮动、强势板块用于识别强弱；明日优先/降权/禁入用于执行取舍 |
| 回避方向 | 禁入行业直接回避；降权行业只接前排A级且仓位降一档；普通轮动不作主攻 |
| 过热方向 | 只止盈，不追新仓；T5也不开放 |
| 板块同步 | 同三级行业至少 2 只票同方向走强 |

行业主线优先：尾盘选票先看东财三级行业预案里的“明日优先三级行业”，再在对应三级行业内找前排。原“持续主线/上升轮动/强势板块/普通轮动/退潮”用于解释行业所处阶段；新“明日优先/降权/禁入”用于明天执行。强行业今日回调但趋势未坏时，是低吸候选，不是退潮；禁入行业和普通轮动方向即使个股冲在前面，也只能观察或回避。

尾盘最怕“一只票自己冲，板块没人跟”。这种形态即使分数高，也只能观察。

主线强趋势例外：如果概念仍是主线/新晋发酵，个股为龙头或前排且贴MA5上行，可以走S4趋势跟随；这类票不强制要求缩量企稳，但必须满足尾盘承接和硬止损条件。

## 五、第三层：四类尾盘买点 + 一条M5例外

### T1：S1 蓄力启动尾盘买点

适用：M1/M2 为主，M3/M4 只允许 A 级试探。

硬条件：

1. S1 V8 基础评分 A 级，试探模式只接受 A 级。
2. 现价在 MA5/MA10/MA20 粘合区间附近，不追高超过区间上沿。
3. 今日不是放量滞涨，不是缩量假反弹。
4. 上方 5% 内筹码压力只作为风险提示；如果评分不足，不因放宽该项而买入。

尾盘确认：

| 项 | 达标 |
|---|---|
| 量能 | 今日量能温和，不超过 20 日均量 1.3 倍 |
| 位置 | 现价在日内上半区，且没有跌破 MA5/MA10 |
| 承接 | 今日回落后能收回，收盘不在日内低位 |
| 板块 | 板块不弱，且至少有同板块个股同步转强 |

T1 本质是“提前埋伏启动”，所以宁可少买，不能把弱反弹当启动。

### T2：S2 大阳后承接尾盘买点

适用：M2/M3 主攻，M4 辅助。

硬条件：

1. 近 5 日有大阳线，且大阳线有量。
2. 大阳后缩量整理，不能放量砸盘。
3. 现价不跌回大阳线开盘价。
4. 板块处于当前模式准入线内。
5. 最终买点状态必须是“可买”或“小仓”，不能买“等回踩”。

尾盘确认：

| 项 | 达标 |
|---|---|
| 缩量 | 今日量相对大阳线仍缩量，理想区间 0.35-0.70 |
| 守位 | 现价 >= 大阳线收盘价的 0.99，至少不能跌破大阳线开盘 |
| 位置 | 日内收在上半区，上影不过长 |
| 同步 | 所属板块/概念有 2 只以上同步走强 |

T2 是尾盘最稳定的主攻形态：大阳说明资金来过，缩量说明没出货，尾盘守住说明承接还在。

### T3：S3 放量突破尾盘买点

适用：M3/M4 主攻，M2 只做 A 级试探。

硬条件：

1. 收盘价或当前价突破近 20 日高点。
2. 今日量比 >= 1.5，且成交量口径必须为股，不是手。
3. 今日收阳，现价 > MA20 > MA60。
4. 今日涨幅 <= 7%，涨太多不追。
5. 近 5 日涨幅不过热，按模式使用 S3 X2 放宽规则。

尾盘确认：

| 项 | 达标 |
|---|---|
| 放量 | 今日量比 >= 1.5，强势可看 2.0 以上 |
| 突破 | 现价仍站在 20 日高点上方，不能尾盘跌回 |
| 位置 | 日内收在上半区，最好接近最高价三分之一范围内 |
| 盘口 | 外/内比 >= 1.0 更佳，低于 0.8 要降级 |

T3 要买“真突破”，不是买“突破过”。只要尾盘跌回突破位，就转为假突破观察。

### T4：S4 主线趋势跟随尾盘买点

适用：M3/M4主攻，M2只小仓试探，M1常规禁用；M5只扫描A级并交给T5二次裁决。

硬条件：

1. 概念阶段为主线、新晋发酵、主线分歧或强势观察，退潮直接淘汰。
2. 个股是龙头或前排，非主线概念只接受前35%，后排补涨不买。
3. 现价>MA5>MA10，MA20>MA60，且距MA5不超过5.5%。
4. 今日涨幅不超过9.2%，换手率不超过12%。
5. 最终买点状态必须是“可买”或“小仓”；高于入场上沿只能等回踩。

尾盘确认：

| 项 | 达标 |
|---|---|
| 趋势 | 尾盘仍在MA5上方，不能跌破后拉不回 |
| 位置 | 收在日内上半区，主线分歧日要求收盘位置>=65% |
| 同步 | 同概念或同板块前排有同步走强，不是一只票独冲 |
| 量能 | 今日量能0.8~4.5倍20日均量，1.1~3.5倍最佳 |

T4解决“强主线不等缩量”的问题，但不是无脑追涨。只要远离MA5、概念退潮、尾盘承接差，就从跟随变成观察。

### T5：M5技术主线狙击例外

定位：T5不是第五套个股形态，而是M5/退潮环境下对S1-S4A级信号的二次放行闸门。它只解决“全市场弱、少数技术行业逆势强”的情况，不用于抄底弱行业。

数据前提：个股、东财三级行业和三大指数必须是同一交易日最终收盘数据；任一滞后时T5自动关闭，不能拿旧指数计算行业超额。

技术焦点池初始范围：

- 二级行业：半导体。
- 三级行业：通信网络设备及器件、印制电路板、电子化学品Ⅲ、消费电子零部件及组装。
- 焦点池配置统一维护在 `工具脚本/30_候选短股/tech_focus.json`，不得临盘因为某只股票想买而临时扩池。

必须同时满足：

1. 情绪不是“过热”，`market_mode=M5`仍完成S1-S4扫描。
2. 个股属于技术焦点池，且为原策略A级、三级行业近5日涨幅前15%的“龙头”梯队。
3. 所属三级行业的明日档只能是“明日优先”或“降权行业”；禁入、未分级都不放行。
4. 三级行业当日涨幅在全部三级行业前10%，且当日上涨。
5. 三级行业相对三大指数当日平均涨幅至少有 `+2.0pct` 超额。
6. 三级行业当日成交额 / 前20日平均成交额 `>=1.20`。
7. 行业内上涨股票占比 `>=55%` 且至少3只上涨，排除单票独涨。
8. 个股收盘价处在策略买入区，买点状态必须为“可买”；等回踩、等确认、小仓、仅观察一律不放行。

执行上限：

- 明日优先行业单票 `1/12`；降权行业再降一档为 `1/16`，不再叠加“价格确定”或主观信心加仓。
- 同一三级行业最多1只；技术焦点池总暴露不超过 `1/4`；v7当日实际最多新开1只（可另列1只备用）。
- 多只同时通过时，按“行业当日强度 → 龙头梯队 → 原策略评分”取前排，不把同一板块的同步上涨误当成多次独立机会。
- 盘后仍服从方案C：只按收盘价、只接买入区内价格、涨跌停不做、同日卖出不买回、挂不上不追。

## 六、尾盘三项确认（v7已代码化）

每只候选必须额外做尾盘三项确认，由 `offline_screener.py` 直接写入买点状态，不再只靠AI口头补充。

| 项目 | 计算/观察 | 通过线 |
|---|---|---:|
| 今日量能 | 今日成交量 / 前20日平均量 | `>1.20` |
| 收盘位置 | `(现价-日内低)/(日内高-日内低)` | `>=0.50` |
| 板块同步 | 个股当日上涨，且同三级行业上涨股数 | `>=2` |

尾盘强制降级：

| 确认数 | 操作 |
|---:|---|
| 3/3 | 基础买点合格时保留“可买” |
| 2/3 | 最多“小仓” |
| <2/3 | “仅观察” |

盘口外/内比仍作为 `realtime_guard.py` 成交前确认，不与日K三项重复计分。

## 七、综合评分

尾盘专攻综合分 100 分，用于排序，不替代硬否决。

| 模块 | 分值 | 说明 |
|---|---:|---|
| 大盘/情绪 | 15 | 模式、情绪周期、尾盘指数稳定性 |
| 板块/概念 | 20 | 板块强度、概念阶段、同步性 |
| 策略基础分 | 25 | S1/S2/S3/S4 原有评分换算 |
| 尾盘确认 | 25 | 量能、位置、同步、盘口 |
| 买点与风控 | 15 | 价格在买入区间、V8盈亏比、筹码压力 |

评级：

| 综合分 | 结论 |
|---:|---|
| >= 80 | 尾盘可买 |
| 70-79 | 小仓或只买主攻策略 |
| 60-69 | 候选观察 |
| <60 | 淘汰 |

## 八、硬否决清单

踩中任意一项，不做尾盘买入。

1. 过热；M5/退潮下未通过T5技术主线狙击闸门。
2. 板块尾盘明显回落；大盘尾盘跳水时，T5也必须继续满足行业相对强度和收盘承接。
3. 退潮概念、一日游概念。
4. 价格高于买入区间上沿，状态为“等回踩”。S4也不例外。
5. S3 跌回突破位下方。
6. S2 跌回大阳线开盘价下方。
7. 今日涨幅超过 7%，S1/S2/S3不新追；S4上限放宽到9.2%，但必须贴MA5且尾盘承接强。
8. 换手异常过高，主板通常 >10% 回避。
9. 上方 2%-3% 内有明显筹码密集压力，且止盈空间被压缩到不足 1:1。
10. 当天已经有新开仓，或总持仓/同板块暴露超限。

## 九、仓位规则

尾盘模式是 V8 主方案，不默认减半。仓位来自市场模式和策略等级，再根据尾盘确认降级。

| 情况 | 仓位 |
|---|---|
| 主攻策略 A 级 + 尾盘 A + 可买 | 按 `market_mode.py` 模式仓位 |
| 主攻策略 A 级 + 尾盘 B | 模式仓位降一档 |
| B 级候选 | 只允许半仓位或更小 |
| 试探策略 | 使用 V8 试探仓，不因尾盘好看而加仓 |
| 高潮/分歧 | 再乘 0.5 |
| 退潮/M5 | 普通候选为0；T5通过者优先行业1/12、降权行业1/16 |
| 过热 | 0，禁止开仓 |

总控：

1. 全模式每日实际最多新开1只；可另列备用1只，只有主狙击未成交/失效时才替代。
2. 同行业/同概念默认只持有 1 只。
3. 最大同时持仓 2 只，总暴露不超过 2/3。
4. 已有同板块持仓时，新候选必须降级或放弃。

## 十、尾盘执行纪律

买入：

1. 14:40 前不抢，14:55 后不买。
2. 只买“可买”或明确“小仓”的票。
3. 买入价不得高于计划买入区间上沿。
4. 如果 14:40 后快速拉离买入区间，放弃，不追。
5. 买入前必须写下硬止损、软止损、逻辑失效条件。

卖出：

1. D1 到最近压力位或买入价 +2%~2.5%，先卖 50%。
2. 强势目标：S1/S2/S3 为 +4%，S4 为 +6%；剩余仓从最高点回落 2.5%（S4为3%）全清。
3. 盘中跌破买入价 -3%，硬止损。
4. D1 收盘低于买入价 -1.5%，D2 开盘清。
5. D2 尾盘默认退出；没有有效R1授权，不得用主观判断拖延。

### R1：盈利剩余仓的逐日滚动授权

R1不是“取消D2”，而是把D2从机械清仓日改成重新证明持有理由的决策点。只有以下条件全部满足，才允许剩余仓多持有一个交易日：

1. 已完成D1首次兑现，并用 `trade_log.py cashout ID 成交价 --shares 实际卖出股数` 记录；授权时相对原买入价仍盈利≥2%。
2. 五项事实检查至少通过4项：市场环境、板块延续、个股相对强度、价格/量能、剩余赔率；其中市场、板块、价格/量能、剩余赔率四项必过。剩余赔率按“下一压力/目标到当前价的空间 ÷ 当前价到保护线的风险”计算，必须≥1.5。
3. 利润保护线不低于原买入价+1%，低于授权时现价，续签时只能上移不能下移。
4. 单次只授权到下一交易日；到期可重新评估并续签，未续签即恢复D2/D3默认退出。
5. 盘中-6%熔断、原交易逻辑失效、移动止盈、强势目标以及R1保护线失守，均优先于持有授权。
6. R1只管理首次兑现后的剩余仓，不允许净加仓。做T只做“先卖后买”，回补不超过当日已卖数量，收盘仓位不高于授权前剩余仓；全部卖完后再买按新交易处理。

授权必须落库，禁止口头豁免：

```powershell
python 工具脚本/50_交易记录/trade_log.py authorize-hold ID --price 当前价 --protect 保护价 --next-target 下一压力位 --until 下一交易日 --checks market,sector,price_volume,reward_risk --evidence "市场/板块/量价/赔率的事实证据" --invalidation "板块退潮、放量破位或保护线失守"
```
