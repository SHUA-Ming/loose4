## 一、两个来自代码的硬约束（决定了设计形态）

1. **现有 `stock_industry.industry` 太粗，不能用**
   它是证监会国标大类（C39/C38/C26…共 83 类）：
   - C39(645只)把 存储/光模块/半导体材料/消费电子 全糊一类；C38 把 光伏(亏)和锂电(赚)糊一类；C26 把 景气化工和普通化工糊一类。
   - ⟹ 景气因子**必须建在更细的 code / 细分主线级映射**上，另起一份数据，不挂 industry 字段。

2. **四策略打分量纲不同**（S1=16 / S2=8 / S3=6 / S4=10，见 1496 行）
   - ⟹ **不能加固定分**(同样 +2，在 S3 占 33%、在 S1 只占 12%，扭曲跨策略比较)。
   - ⟹ 用**平级 tie-breaker（优先级）**接入，量纲无关，且正好实现你要的"同分优先"。

## 三、代码接入点（精确到行，最小侵入）

**① 加载配置（在 line ~375 industry_map 之后）**
```python
import json, pathlib
_boom_cfg = json.loads((pathlib.Path(__file__).parent / 'boom_tier.json').read_text('utf-8'))
_theme_tier = _boom_cfg.get('theme_tier', {})
_code_theme = _boom_cfg.get('code_theme', {})
def _boom_tier(code):           # 1=最景气 … 4=回避；None=中性
    return _theme_tier.get(_code_theme.get(code, ''), None)
BOOM_TILT_ACTIVE = False        # 总开关：先 False 影子跑
BOOM_SCORE_BAND  = 2            # "分值相近"的档宽：score 差≤2 视为同档
```

**② 给候选打标（在 line ~1467 `for c in all_candidates:` 循环里，一处即可，不碰四个策略）**
```python
for c in all_candidates:
    c['_buy_status'] = _buy_status_for_candidate(c)
    t = _boom_tier(c['code'])
    c['boom_tier']  = t
    c['boom_label'] = {1:'🟢景气T1',2:'🟡T2',3:'⚪T3',4:'🔴T4',None:'·'}[t]
```

**③ tie-breaker 函数（在 line ~1458 get_mainline_bias 附近）**
```python
def get_boom_priority(c):       # 越小越靠前；中性(None)/T3 居中
    return {1:0, 2:1, None:2, 3:2, 4:3}.get(c.get('boom_tier'), 2)
def score_band(c):              # 把分数分档，让"相近分"并列 → 同档内景气优先
    return -(round(c['score'] / BOOM_SCORE_BAND))
```

**④ 合并排序键（line 1472，仅在开关打开时插入）**
```python
if BOOM_TILT_ACTIVE:
    key = lambda x: (buy_status_priority.get(x.get('_buy_status'),9), get_strategy_priority(x),
                     get_concept_priority(x), get_mainline_bias(x),
                     score_band(x), get_boom_priority(x),   # ← 同档内：景气好的优先
                     0 if x.get('tier')=='龙头' else 1, -x['score'])
else:
    key = lambda x: (buy_status_priority.get(x.get('_buy_status'),9), get_strategy_priority(x),
                     get_concept_priority(x), get_mainline_bias(x),
                     0 if x.get('tier')=='龙头' else 1, -x['score'])   # 原逻辑，零改动
dedup_results = sorted(all_candidates, key=key)
```
> 关键：用 `score_band + get_boom_priority` 实现**"分数进同一档(差≤2)时才让景气插队"**，不会用景气覆盖明显的技术分差距。这精确对应你"分值差不多就选好行业的"。

**⑤ 展示列（line ~1487 打印循环，Phase 1 就上，纯展示）**
在候选表加一列 `景气`= `c['boom_label']`；再打一段"景气加权后 TOP(影子)"对照榜。

## 五、边界与不做的事

- **只影响排序/展示，不碰买点判定和仓位/风控**（尊重"放松风控慎行"）。
- ★价格驱动主线(存储/钨/贵金属/化工)：Q2 价格回落要及时在 JSON 里降档——因子只反映"当前景气判断"，不是永久。
- 覆盖不全≠不好；未归类的票按原逻辑走，不冤枉。
