# 申万三级行业轮动（sw_rotation）说明

## 为什么加这套

原有两套行业/板块口径都有硬伤：

| 口径 | 表 | 数量 | 级别 | 问题 |
|---|---|---|---|---|
| 证监会大类 | `sector_daily` | ~86 | 大类=二级，单层 | 太粗，C39把机器人/算力/电子/PCB全塞一桶，抓不到细分轮动 |
| 同花顺概念 | `concept_daily` | 377 | 扁平不分级 | 重叠噪声大（一股属多概念）、上游滞后一天 |
| **申万三级** | `sw_industry_daily` | **336** | **一级31→二级131→三级336** | ✅ 能分级、不重叠，指数可回溯，做细分轮动最干净 |

结论：细分板块轮动用申万三级当骨架。三级定方向，选股再落到主板龙头。

## 数据表（建表在 `00_公共核心/db_cache.py` 的 `init_db()`）

- `sw_industry_info(code, level, name, parent_name, member_count, pe_ttm, pb, update_date)`
  一/二/三级全存，`parent_name` 是上级行业名（三级→二级名，二级→一级名），可拼三层树。
- `sw_industry_daily(code, date, open, high, low, close, volume, amount, pctChg)`
  各级行业指数日K，`pctChg` 由收盘价推算。默认只灌一级+三级。
- `sw_industry_member(l3_code, stock_code, stock_name, update_date)`
  三级→成分股映射（"从走强三级挑主板龙头"的桥）。成分慢变，每周刷一次即可。

## 更新数据（写库，`10_数据更新/`）

```bash
# 日常：刷新三层树信息 + 一/三级近250日K（约367个指数，几分钟）
python 工具脚本/10_数据更新/_fetch_sw_industry.py

# 首次或想多留历史
python 工具脚本/10_数据更新/_fetch_sw_industry.py --full --days 400

# 刷新三级成分股映射 → sw_industry_member（爬 legulegu，慢，每周一次够用）
python 工具脚本/10_数据更新/_fetch_sw_industry.py --members-only

# 日K + 成分一起
python 工具脚本/10_数据更新/_fetch_sw_industry.py --members

# 只刷新三层树信息，不动日K
python 工具脚本/10_数据更新/_fetch_sw_industry.py --info-only
```

数据源：akshare `sw_index_first/second/third_info`（信息）+ `index_hist_sw`（日K）+ legulegu 成分表（成分）。
申万指数与个股一样收盘后出，**同样可能滞后一天**（傍晚跑）。

## 分析轮动（只读，`20_市场环境/`）

```bash
python 工具脚本/20_市场环境/sw_rotation.py                 # 最近两周(10个交易日)三级轮动
python 工具脚本/20_市场环境/sw_rotation.py --window 5      # 只看最近一周
python 工具脚本/20_市场环境/sw_rotation.py --as-of 2026-07-03
```

四档分类：
- **① 持续领涨**：两周多数日排名前20%，主线级别，回调优先在这里找票。
- **② 加速轮入**：后一周排名明显跃升、资金正在切入，刚轮到的方向。
- **③ 稳步抬升**：累计涨幅居前、多数日收红的温和走强。
- **④ 高位退潮**：前强后弱，减仓回避方向。

默认带"走强三级·主板龙头"段：读 `sw_industry_member` + 本地 `kline_daily`，给每个走强三级列成分股的
两周涨幅+今日涨幅，`★`=主板00/60可买、`○`=创业/科创/北交买不了。个股K有到最新交易日，能看轮动是否延续到今天。
`--no-leaders` 可跳过（更快）。也可导入：`from sw_rotation import analyze; r = analyze(window=10, with_leaders=True)`。

## 已知限制

- **申万官方"三级→成分股"接口全坏**（akshare 1.18.41：`index_component_sw` KeyError、`sw_index_third_cons`
  因上游多一列贴错列名 ValueError）。桥的做法：`_fetch_sw_industry.py --members` 直接爬同一 legulegu 页面，
  **按列位置**取 代码(第1列)/简称(第2列)，避开坏掉的列名，写进 `sw_industry_member`。做轮动本身不需要成分（三级指数日K就够）。
- 申万现行三级列表 336 个，但其中约 78 个是 2024-06 改版后**停更的旧代码**（信托/农用机械/电信运营商等，`index_hist_sw` 只剩老数据），分析会自动剔除，实际参与约 **258** 个活跃三级。`sw_rotation.py` 表头会打印 `258/336`。
- 三级指数是全市场口径，含创业板/科创板。**用户只能买主板(00/60)**，选股时仍要在成分里过滤主板。
- MySQL 铁律：`sw_rotation.py` 是纯分析，只读连接、不调 `init_db()`；建表/写库只在 `_fetch_sw_industry.py`。
