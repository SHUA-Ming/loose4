# 长期持有股票

长期股筛选、持仓跟踪、估值复核、基本面/趋势复盘流程统一放在这里。

和短线股共用的数据连接、行情接口、市场环境判断，应沉淀到 `../00_公共核心/` 或 `../20_市场环境/`。

## 当前策略文档

- `中长期选股策略.md`：用于 10 到 60 个交易日的中长期趋势股票，定义市场适用条件、候选来源、硬过滤、100 分评分体系、买点模型、分批建仓、卖出风控和持仓复核节奏。

## 与短线系统的边界

中长期股票不使用短线 D2/D3 强制清仓，也不使用 +4% 必卖一半的短波止盈。短线 S3/S4 候选如果要升级为中长期持仓，必须重新按中长期评分、趋势结构、板块持续性和仓位上限复核。
